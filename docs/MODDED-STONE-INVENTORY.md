# Complete pinned-JAR stone-family inventory — B14

**Data origin:** blockstate identifiers, localizations, and bundled worldgen/structure JSON from all actual hash-verified Minecraft 1.21.1 NeoForge **server** JARs in the test pack.
**Status:** comprehensive static scan of loaded pack artifacts; NOT a world-generation, creative-tab, harvest or in-game registry test. Names may be missing for unlocalized blocks.
**Coverage:** 142 server JARs; 2450 candidate stone-family blockstates, 545 possible primary stones, 1856 worked variants, 49 ore-bearing stones.
**Evidence:** 31 primary stones are referenced in bundled worldgen/structure JSON. Absence of a reference does not prove an item cannot naturally generate: mods may register features in Java, templates or runtime datapacks.

The machine-readable full inventory at \`manifest/modded_stone_inventory.json\` lists EVERY matching block ID and its originating pinned mod, variant/ore classification, and concrete JSON paths.

## Generator policy (proposal only)

- Galore **is installed for testing**, but no custom modded-stone recipes are installed.
- Use a seed block (placed below generator) for building-stone renewability; retain world discovery.
- Never automatically generate ores, rare/ritual items, bosses' materials or Aquamarine Shale from ordinary water/lava.
- Astral Aquamarine Shale is already a weighted Liquid Starlight + lava Chalice product, **with fluid consumption**. Defer a non-consuming late-game source until ProjectE/miner gating is designed.
- Botania Livingrock, Occultism Otherstone, and similarly native magical transformations should not be duplicated before testing native cost/progression.

1. Verify distinct Astral/other-system **Marble** blocks through JEI, Jade and naturally spawned biome samples; IDs distinguish genuine duplicates from one mod's variants.
2. Check distinct **Darkstone/Blackstone/Scoria/Basalt** families and whether they generate by worldgen, structures, ores or crafting.
3. Find the real starter source/biome and confirm a block can be used as a Galore \`modifier\` seed block.
4. Run \`spark\` measurements of a 100-generator production test at matching items/second and compare with lava+water world-block farms. Stop generators by filling output chest and retest after chunk unload/reload.
5. Test decorative variant inventory/JEI and resist adding new generators for processed Livingrock/Otherstone, magical blocks, boss materials or ore duplicates.
6. Assess the **Aquamarine Shale** shop route only after deciding if it is progression-safe and which currency balance is acceptable. Do not grant free early stacks.

## Interpretation constraints

This script uses \`assets/*/blockstates\` plus names, not the runtime registry. It filters likely geological blocks using explicit substrings, so an unusual non-stone-named geological material can be missed and there may be false positives. The complete namespaced ID/evidence ledger makes omissions and classifications auditable. Client/JEI/worldgen tests are required before claiming an exact natural-spawn inventory.
