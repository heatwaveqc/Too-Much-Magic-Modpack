## Executive assessment

**Design cohesion: strong. Delivery: substantial foundations, with a large unfinished feature tail. Gameplay acceptance: early.**

The core vision remains a *magic-first* pack with multiple viable schools, meaningful transformations and class progression, limited exceptional technology, renewable but appropriately gated resources, questbook-as-walkthrough, and a Draconic/Chaos/ProjectE apex. There are **165 mod selection records, 156 `enabled_in_pack=true`, and 9 inactive/planned** in `manifest/mods.json`; these are selection records, **not a guarantee that the latest integrated artifact contains or can play all 156**.

The generated [full feature checklist](FEATURE-CHECKLIST.md) contains **112 acceptance criteria across nine tracks**: **5** owner-reported bounded player PASS, **13** partial player checks, **21** server-smoked but mechanics unverified, **20** source-ready unverified, **11** in progress, **41** planned, **1** blocked. A PASS is narrower than full release sign-off; the latest build needs its own regression results.

The 2026-11-15 targeted TeamLapen retirement merged as [PR #165](https://github.com/heatwaveqc/Too-Much-Magic-Modpack/pull/165), with metadata/QA repairs [#167](https://github.com/heatwaveqc/Too-Much-Magic-Modpack/pull/167) and [#168](https://github.com/heatwaveqc/Too-Much-Magic-Modpack/pull/168). **This test is intentionally not an all-feature union:** the [integration source registry](../manifest/integration-sources.json) separately lists deferred work. Server-side source/CI progress must not be read as a passing client or survival test.

## High-priority verification sequence, *after* current test artifacts are frozen

1. **Integrity and boot:** inspect the generated BUILD-MANIFEST and actual Mods screen; verify no retired TeamLapen pins, exactly one first-party `tmm_progression` JAR, packwiz hash chain, current quest registry, start fresh disposable client/world and dedicated-server join. Record the actual SHA and run.
2. **Core progression:** Monk natural First Sunset, XP grant, skill tree buy/equip/relog/armor restriction; Hunter enrollment, silver-specific damage and opposite cases; JAWR vampire and lycan states without a duplicate blood owner. **Report missing advanced draft features as NOT BUILT, not failed.**
3. **Critical regression:** quests/claim-once/shop currencies, canonical silver equipment, dragon foods, Neo Vitae canonical dust, targeted Mahou native Catalyst Exchange, no reintroduced KubeJS entity tick shim.
4. **Next all-feature candidate:** reconcile explicitly deferred and stacked branches first. Prioritize Tyz/MXP earning, Monk/Hunter completeness, ProjectE gates and EMC audits, 17 Gateways, BetterEnd and world additions, Thermalily module migration, and creature targeting — with staged server/gameplay QA.
5. **Release conditions:** verify no portable bag nesting, no forbidden ring acquisition, no economy/EMC dupes, legitimate boss/item progression, save-reload + two-player isolation, and sustained performance. Do not promote based solely on compilation or server startup.
