# Gilded lava-fishing integration and compatibility audit — 2026-11-16

**Status:** Java source and optional food tags compiled in isolated Gilded branch; both full-content mods **tagged desired for next authorized Gilded QA**, not installed/hash-pinned, and never tested in a client/world yet. Read actual live status below; no full pack build/smoke was triggered by this design stream.

## Selection: two *content* providers, not the duplicate-hook addon

**Desired for the same upcoming QA:**
1. **Lava Fishing**, TeamSunset \`lavafishing-1.21.1-1.2.13-all.jar\` (NeoForge, CurseForge project 1035887, file 7781402, [official file](https://www.curseforge.com/minecraft/mc-mods/lavafishing/files/7781402)). Depends on Aquaculture 2 and Kotlin for Forge, both already installed. Adds rods, fish, aqua lava hooks, lava/Nether tables, gold nuggets, Netherite scrap and other separate content.
2. **Nether Depths Upgrade**, \`netherdepthsupgrade-3.3-1.21.1-NeoForge.jar\` (CurseForge project 670011, file 8940364, [official file](https://www.curseforge.com/minecraft/mc-mods/nether-depths-upgrade/files/8940364)). GeckoLib already installed. Adds its **own** lava rod/bobber, 9+ Nether fish types, fish-based crafting, vents/worldgen, lava sponge and lava glass. **v3.3 is the newer 1.21.1 target**, replacing earlier v3.2 suggestions. Note its Netherite-ore vent rates may shift economy, even before fishing.

**Do NOT also install \`aq2lava\` / Aquaculture 2: Lava Fishing Addon** as an additional third mod in the same pack. Inspection of official \`TeamMetallurgy/Aquaculture2-Lava-Fishing-Addon/src/main/java/.../AQ2Lava.java\` and tagged \`teamsunset/LavaFishing@1.21.1-1.2.13/registry/ModItemsAqua.kt\` shows **both register the same six aquaculture hook names** (\`obsidian\`, \`double_obsidian\`, \`glowstone\`, \`quartz\`, \`soul_sand\`, \`obsidian_note\`). Duplicate item registration is a strong concrete conflict. The extra addon provides no catches of its own. Only reconsider it as an alternative replacement for full Lava Fishing after changing registration. \`manifest/mods.json\` on exploratory and integration branches records the two selected content mods as \`desired: true\`, \`enabled_in_pack: false\`, batch B17; the AQ2-only addon is explicitly excluded.

**Coexistence of the two selected content mods is plausible but not yet established in-world.** They use different registries/loot systems: full Lava Fishing adds its \`lavafishing:\` tables through Aquaculture \`AquaLootTables\`, while Nether Depths uses \`netherdepthsupgrade:gameplay/lava_fishing\` and \`.../nether_fishing\` via its own custom lava bobber. Do not blindly overwrite/merge their loot tables or install both sets of rod/loot patches without testing. The two providers add real separate item/worldgen content and may be complementary.

## Gilded fishing permission — now native rank 1 (no level-12 gate)

The owner requires **lava-fishing permission as soon as the Gilded ritual succeeds**. It does **not** require Gilded level 12, level 18, a purchased Tyz skill or immunity to burning. The standalone server \`runtime/GildedFishingRules.java\` currently:
- Checks any \`FishingHook\` entity in a lava block or one above it at \`EntityTickEvent.Post\`: non-Gilded owner hooks are discarded. Both vetted content providers' source bobbers extend \`FishingHook\`, so the same actor-and-fluid check covers both. Non-Gilded water fishing remains unaffected.
- Rejects unlicensed \`ItemFishedEvent\` at event priority **HIGHEST** as backup before \`AnglersHatItem.onItemFished\` can generate reward orbs; credits at priority **LOWEST** after ordinary loot listeners. If another mod ignores cancellation, the server-tick discard is still essential.
- Grants **provisional 5 native Gilded XP per successfully nonempty lava fishing event**, using the existing \`ProgressionApi.recordExternal\` and active Gilded \`activities\` key \`tmm_progression:gilded_lava_fish_caught\`. One award per hook UUID, regardless of fish count, Aquaculture's double catch, Angler's Hat extra drops or multiple output stacks. No Gilded XP from other (water) fishing, casts, empty reels or mere time in lava.
- Cave Dragons are a possible *separate* licensed species. Their permission is **not yet implemented** and must verify a real Dragon Survival Cave form on server before enabling. Cave-only permission would **not** grant Gilded XP to non-Gilded dragons.
- No Gilded virtual Fortune applies to fishing: Fortune still belongs to active gold/Netherite **block-mining loot** only. Vanilla Luck of the Sea/rod hooks/other real fishing buffs should remain functional.

**Native fire immunity** is unrelated to fishing permission: at Gilded **level 18**, \`Undying Ember\` is inspired by zombified Piglins and blocks **every damage type in \`#minecraft:is_fire\`** (including lava, direct flames, burning, campfires and tagged modded fire), while clearing existing burn ticks. This is full fire-and-lava immunity, **not** generic damage immunity.

## Gilded food and catch provenance

- All actual *edible* lava fish and cuisines from Lava Fishing and Nether Depths listed in optional \`#tmm_progression:gilded_lava_catch_foods\` have item-type permission (22 provisional registry IDs; **validate actual 1.21.1 item IDs and food properties**). This tag is nested into \`gilded_nether_foods\` as an optional list; missing mods or inedible catches don't authorize arbitrary food.
- Catch loot may include already-vanilla edible foods **not normally Nether-whitelisted**: Nether Depths \`gameplay/lava_fishing/fish\` currently lists **cooked cod, cooked salmon, cooked chicken and spider eyes**. Global whitelisting all cooked chicken/cod would defeat the restricted diet. Instead the Java fishing hook attaches \`minecraft:custom_data\` key \`tmm_progression:lava_caught=true\` to actual edible items in \`ItemFishedEvent\` when hooked in lava, and \`GildedRules.isAllowedFood\` accepts marked stacks. Marked fish get **ordinary** food values; only foods with genuine gold ingredients receive Gilded's 2x golden-food nutrition/saturation.
- Nonfood rewards—gold nuggets, Netherite scrap, weapons, books, valuables—do not need diet whitelisting. Crafting a meal from a lava fish may strip the provenance marker; new recipe outputs require separate food-item tags or an explicit recipe inheritance design, not a wildcard mod namespace.
- **Critical in-world proof:** confirm a fished ItemStack's custom component survives Aquaculture/Nether Depths event-list copies and transfer into inventory. If it doesn't, move the provenance mark to a guaranteed final drop-stack hook. Do not quietly whitelist all cooked chicken as a shortcut.

## Live QA matrix before integration acceptance

1. **Both content providers simultaneously**, exact versions/hashes, NeoForge 1.21.1 server and client; ensure hook registry has no duplicates, distinct rods work, all mod entity types and loot tables register, server doesn't crash. Check Nether Depths vent/worldgen and Netherite economy.
2. Newly initiated Gilded at level **1** can fish lava in Nether **and Overworld**; ordinary non-Gilded and off-path player cannot. Level-12 dependence is prohibited; no unintended water-fishing restrictions. Cave Dragon is pending.
3. Catch 1 fish vs several items, Aquaculture doubled hook and Angler's Hat's repeating catches: Gilded XP is **one +5 credit per actual successful bobber**, not per result/extra stack. Multiple unique casts should get independent credits; no empty cast or denied result gets XP.
4. Verify \`ItemFishedEvent\` source from both modded bobbers against this exact runtime, event priority and canceled behavior; ensure a canceled illegal catch cannot still trigger Angler's Hat bonus drops or scrolls.
5. Fish diet: all recognized edible lava fishes/cuisines allowed; cooked cod, cooked salmon, cooked chicken and spider eyes obtained via lava **allowed only when marked from actual lava catch**. Same foods obtained from ordinary crafting/Overworld sources stay disallowed except if separately allowed by gold/Nether recipe rules. Catch items and modified stack provenance survive inventory transfer, relog and consume.
6. Test Improvable Skills \`Luck of the Sea\` + \`Experience Harvesting\` on both bobbers, with hat equipped/unequipped. Specifically test old repeated skill-scroll issue #38, XP orb amounts vs native Gilded XP, loot table choice, splash speed, catch rate and claimed skill XP. No infinite scroll/XP exploit.
7. Test hat \`Generous Catch\` at rank 0/max, its constellation, plus its own bonus \`BuiltInLootTables.FISHING\`. Ensure it does not turn lava catches into wrong loot or give Gilded XP from extra rolls; verify its extra **water** fish remain distinct from official lava fish diet.
8. Full **\`Undying Ember\` level-18 fire immunity**: level 17 still burns, level 18 resists lava, flame, burn ticks, blaze/campfire and correctly fire-tagged modded attacks anywhere. Untagged magic, explosions, wither, void and kinetic damage remain effective. Death/relog/rank loss/reload resets effects.
9. Validate Nether fish edible items (optional tags) and fish recipe outcomes on actual registries; check client/JEI, no stale names. Also assert only owner-approved full content mods are selected—not AQ2 addon.
