# ATM10 relationship

This project is **not** an ATM10 fork or redistributable copy. ATM10 is the inspiration for performance libraries, client QoL and configuration strategy only.

The ATM10 8.5 baseline is Minecraft 1.21.1 / NeoForge 21.1.265 per an independently documented portable layout: https://github.com/MarkZamore/All-The-Mods-10 . This is **provisional**, not an official compatibility certification for Too Much Magic.

Do not copy ATM10's config overrides, assets, scripts, quests, or JARs without provenance/permission checks. Review individual upstream mods and pin exact builds. No automated 'import all' operation.
