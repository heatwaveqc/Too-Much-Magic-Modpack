# Cross-mod interactions

Use [the cross-mod template](../templates/CROSS-MOD-INTERACTION.md). Name a file `<id-a>--<id-b>--<purpose>.md` with manifest IDs alphabetically, or list further participants in the file.

Separate independently useful interactions. Examples of *questions*, **not proven compatibility**, include alternate magic inputs, item/energy handoffs, entities and faction behavior, enchantment/spell integrations, food/diet exemptions and resource automation. Identify the actual bridge and mark its evidence status.

Add new reports to [the coverage index](../INDEX.md) and link them from each participant profile.
