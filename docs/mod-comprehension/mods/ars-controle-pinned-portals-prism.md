## Actual Source formula and operation order

Tile cost defaults minDistance1024, perBlock.03125, dimension2000, maximum−1(unbounded). For squared coordinate separationd² and thresholdm: when d²>m², cost=max(0,integertruncate(min(maxCost,dimensionCost+sqrt(d²−m²)×perBlock))); otherwise max(0,dimensionCost). This is **sqrt(d²−m²)**, not distance−threshold. Crossdimension comparison still uses numeric coordinates. Maxcap only applies in above-threshold branch; within threshold returnsdimensioncostdirectly. Config/current settings may differ.

Prism onHit resolves target and adds region ticket at destination **before Source payment** when loadTime>0(default600ticks,level3,tickingtrue); loadTime≤0 instead rejects unloadedtarget. It may recreate projectile in newdimension via entity restore/resolver/statecopy and remove original asCHANGED_DIMENSION before later block-target payment. Failed recreation isn't guaranteed successful crossdimensionmove. Creation/ticket side effects aren't refunded by payment refusal.

Crucially **entitytarget branch returns before the Source payment code**. It checks alive, posts cancellable SpellProjectileHitEvent, resolves effect on entity and discards projectile; tile.sourceNeeded quote exists but isn't collected on this branch. Don't state both target kinds always pay quotedSource or teach this as approved free remoteattack.

Blocktarget branch moves projectile first, then requests Source at originPrism with range19 if costpositive; failure witchparticles/discards. Increments prismRedirect and at≥3rewards nearby native Prismatic trigger (not pure author attribution). Destinationcollision posts event and resolves block/firstentity effect then discards; cancellation returns after already incurred ticket/movement/payment. If no collision, backs position up one velocity step to continue flight. Observer updates after successful branch. Original spell personal mana remains native cast cost, distinct from optional PrismSource.
