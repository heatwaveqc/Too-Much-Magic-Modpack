## Flashpine is a planted pod, not free fruit from every grown tree

`ars_elemental:flashpine_pod` item is registered ItemNameBlockItem with food; block is native **ArchfruitPod extends CocoaBlock**, survival override accepts adjacent supporting block in Flashing-logs tag. It retains age0..2 Cocoa behavior. Place pod against matching log/wood, let it mature, break to harvest and replant one: packaged loot gives **three pods at age2, one otherwise**. This supports a material renewal route after finding an initial pod, not a measured farm rate. Growth/Bone Meal/side placement follow inherited native/vanilla mechanics and need acceptance.

Important bootstrap distinction: configured **natural_flashing_tree has isWorldGen=true**, while **flashing_tree_sapling=false**. Native MagicTrunkPlacer only attempts attached pod placement when isWorldGen and trunk layer≥2 and below height−2; per checked trunk face-position call random≤0.07, chooses direction/age0..2 and requires air. It sets pod light6+age. Thus planted sapling tree does **not** use those natural pod attempts; do not promise each regrown tree creates new starter fruit. Find natural pods, retain/replant harvested fruit. Native ArchfruitPod also accepts Light spell to set light clamp(8−DampenCount,0,8); that is illumination, not an automatic growth/Source input.

Typed uses include Flashjack wild conversion/familiar feeding, Shocking thread, Discharge glyph and optional potion recipe; see [Flashjack](ars-elemental-pinned-flashjack.md), [threads](ars-elemental-pinned-threads.md), [Fire/static glyphs](ars-elemental-pinned-fire-static.md). Eating registered Flashpine gives nutrition4/saturationModifier0.6, alwaysEdible, independent effect suppliers: Night Vision600ticks40%, Glowing60040%, native Shocked60080%, addon static_charged60020%. It is not a universally safe/beneficial food or evidence of compatibility with faction/diet restrictions. The charged effect's real lightning recipient is in the thread audit; don't flatten it to harmless sparkle.

## Sparkflower and Source Vines

Sparkflower `ars_elemental:sparkflower`: FlowerBlock with native Shocked effect parameter200.0f, block light8, ordinary self-drop and potted variant. One flower shapeless→one Glowstone Dust. The constructor parameter is effect-duration input to vanilla FlowerBlock, **not** proof of200tick contact damage or an exact food duration without vanilla consumer conversion. Flower worldgen placement is in the biome branch; no arbitrary interaction/status farming asserted.

`source_vines` head and `source_vines_plant` body are custom registered CaveVinesBlock/PlantBlock subclasses pointing to one another; no separate collectible item is registered. Light uses CaveVines.emission14. Clone-pick returns **native Sourceberry** item. Both override useWithoutItem with shared harvestBerry: if BERRIES=true, pop exactly one native Sourceberry, play harvest sound, set berries=false, update/game-event; otherwise PASS. No Source cost. Breaking either has packaged loot of `minecraft:air`, so do not teach ordinary breaking as harvesting a portable vine. Sourceberry can serve native berry uses, but its item is not a placer for this custom vine head.

Inherited vine growth/Bone Meal state paths are not modified here; exact renewal and generation cave placement remain acceptance/worldgen topics. Blueprint config has downward block columns and random berry-bearing states, not a generic seed craft. [Urn](ars-elemental-pinned-guide-urn.md) water supply does not itself manufacture vines or guarantee berries.
