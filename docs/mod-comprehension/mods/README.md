# Mod profiles

One file per `manifest/mods.json` ID: `<manifest-id>.md`, created when actual research starts using [the profile template](../templates/MOD-PROFILE.md).

The profile answers how the mod works in survival, **all the steps of its progression from guidebook acquisition to final milestone**, its precise typed input/output contracts, what it does unusually well, internal synergies, cheap useful setups, exposed hooks and limitations. Every major structure/build should have the exact in-game reference and enough instructions to become a rewarded how-to quest; see the [walkthrough standard](../../QUEST-WALKTHROUGH-STANDARD.md). A no-content library can have an interface-focused note.

To find existing work and the next mod, use the [coverage index](../INDEX.md). Do not create hundreds of empty per-mod files; a queued row is the placeholder until real findings exist.
