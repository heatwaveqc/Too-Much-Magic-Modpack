## Acquire and assign a geode workshop

Use native Notebook **Crafting → Amethyst Golem Charm**, including summoning/farming/storage pages, related **Awakening / Dominion Wand / Dowsing Rod** entries and Ritual Index → Awakening. First find Budding Amethyst in a geode; run Awakening within its target bounds (brazier search bounds3,1,3) without Book and Quill augment. Ritual replaces a Budding Amethyst block with air and creates golem there. This trades the original budding block for worker; it is not a shapeless charm recipe or proof the geode has endless remaining buds.

Use Dominion Wand **golem first → intended home/storage block last**. First callback sets any nonnull BlockPos as home; choose ordinary inventory with a null-side ItemHandler so pickup and deposit goals can run. Callback does not validate inventory or a numeric range, so successful home_set message is not proof of functional storage. Set home near your Amethyst/Budding Amethyst cluster field with accessible ground and enough free faces for growth. Without home the main work suppliers refuse.

Dispel your golem to get an Amethyst Golem Charm plus held stack; interaction consumes no new budding block. Charm use spawns golem at clickedBlockX/Z, Y+1, successful shared charm use consumes one survival item. No check of spawn success in method. Reassign home after moving; persistent charm data carries name/color, not a demonstrated restored working home. Familiar Binding instead removes eligible golem to produce familiar script; that defensive familiar is a separate role and does not run this workshop.

## Scanning and four work branches

Home scan immediately when cooldown0, then every3600server ticks: X/Z±5, Y-3..+10 around home. Records blocks matching any registered budding-conversion recipe and blocks in `ars_nouveau:golem/budding`. Native single conversion is `recipe/budding_conversion/budding_amethyst.json`: **Amethyst Block→Budding Amethyst**; no item/Source ingredient in that recipe type. Native budding tag contains only Budding Amethyst, cluster tag only full Amethyst Cluster, item `golem/shard` only Amethyst Shard. Addon/effective tag contributions may extend these; do not promise all modded crystals work.

| Work | Actual cadence, input/output and failure boundary |
| --- | --- |
| Convert | Requires home, empty hand, convertCooldown<=0 and recorded convertible blocks. Starts120tick timer; within distance2 clamps remaining timer to<=40, but expiration can call conversion even if still distant. Rechecks current block against first matching recipe, sets result default blockstate, then convertCooldown6000 even if no match remained. No Source or shard debit in this conversion method. |
| Grow | Requires home, empty hand, cooldown<=0 and recorded budding blocks. Starts120tick timer, paths toward a selected one, then iterates valid tagged blocks; `numGrown>3` break allows **up to4** block randomTick calls, not three guaranteed clusters. Sets cooldown300. Random tick can do nothing depending on native block/available faces. Doesn't consume a budding block. |
| Harvest | Requires home, empty hand, !imbueing, cooldown<=0 and budding list. Shuffled list,130tick action; at remaining ticks divisible40 tries first recorded bud with an adjacent tagged cluster, harvesting every matching face around that bud, then removes that bud from current action list. Typical four possible timed attempts120/80/40/0; sets cooldown1200 on finish. Uses fake-player Diamond Pickaxe playerDestroy then safe destruction without extra drop request; no Fortune/Silk augment in this method. Protection/full acceptance distinct from attempted loot call. |
| Pickup | Requires home ItemHandler and cooldown<=0. Searches ItemEntities in box inflate10 around **home**, native shard tag. Starts80tick timer; approaches chosen item, but timer expiration calls collectStacks regardless of arrival. collectStacks iterates all tagged item entities in that home box, takes whole first stack if empty, merges later by Item identity up to stack limit; doesn't check pickup-delay/owner/protection metadata here. Sets pickup backoff60..69 on stop. |
| Deposit | Requires nonempty hand and null-side ItemHandler at home. Moves toward home, deposits within distance2 or after80tick timer regardless of travel. Uses insertion remainder as held stack. Full/missing handler retains held item; route isn't evidence of completed delivery. No world-drop overflow in this method. |

No Source/XP/food fuel checks in those inspected goal methods. This is ordinary crystal production after actual Awakening/material acquisition, not permission to extend arbitrary protected loot or rare crystals through tags. Parent source regeneration/processing can consume the resulting shards for Source Gems; exact rates require measured block random ticks and goals, not a fixed guaranteed items-per-second claim.

Goals have differing priorities and state suppliers; the inspected work goal classes don't set movement flags to mutual exclusion. Don't add conversion/grow/harvest rates as independent fully parallel guaranteed machines. Cached lists change only on scan; converted/new blocks may not immediately appear in other lists. Full output can leave hand occupied, preventing empty-hand work until delivery.

## Control, persistence and acceptance

No redstone-off check in these golem/home callbacks or goal suppliers. Changing home does not immediately reset scanCooldown in setHome; a newly assigned workshop may wait for or use old cached scan state until refresh. Home/cooldowns/held items have entity save behavior, but actual unload/relocation/protection behavior must be observed. Native healOverTime helper is called by tick; exact heal policy/rate not established by this worker audit. Do not promise invulnerability from class name or animation.

Quest lesson: obtain own golem from a real Budding Amethyst → valid inventory home → one ordinary Amethyst Block conversion → random-tick cluster growth → actual harvested/inserted shards → optional move via charm or bind familiar. Cite named Notebook/ritual/JEI pages; item/charm acquisition task is only proxy. Use XP and ordinary workshop supplies as rewards, without bypassing an unvisited encounter/gated resource.

Positive/boundary tests: correct/no home, noninventory/sided-only home, scan bounds/new-home cooldown, conversion0..6000timer, tag mismatch/removed target, closed budding faces, four grow attempts vs no actual growth, full cluster vs immature buds, dropped items with delay/owner, unreachable route vs timed remote action, full chest retained stack, concurrent workers, Dispel held stack, charm spawn obstruction and reload. Count placed blocks, dropped/held/stored shards and Source separately. Parent remains researching for other equipment/devices/addons/pilot.
