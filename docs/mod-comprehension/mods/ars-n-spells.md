The addon connects spell carriers, mana, regeneration, equipment and school combat across Ars and Iron's. Its survival endpoint is a working transcribed/bound cross-cast plus player-selected utility/specialization options. It has no separate boss, mandatory250cast grind or independent book-tier ladder. Parent spell/gear progression remains relevant; the addon does not approve bypassing other mods' learning gates.

## Complete survival route

1. **Loom.** Craft `ars_n_spells:spell_loom`: grid` G /LBL/OOO`,GGoldIngot,L2Lapis,BBook,O3Obsidian. Craft Blank Scroll from Blank Parchment+Source Gem if needed. Right-click Loom, put spell-bearing Ars source in slot0and blank Iron's Scroll or addon Blank Scroll in slot1, leave outputslot2empty. Name/cosmetics optional. Use inscribe; collect the real Iron's carrier. Normal mode refuses filled target, conversion explicitly blanks one copy. Output is one carrier; reusable book/focus source remains, consumable parchment/scroll source costs1. There is no XP/Source/mana fee in this Loom transaction; a later cast pays separately.
2. **Bind.** Choose native Iron's Inscription Table or the addon Spellbook Binding ritual. For ritual tablet, use Apparatus recipe `ars_n_spells:apparatus/spellbook_binding`: consumed Novice Book reagent, Iron's book-tag item+Iron's Scroll+Source Gem Block+Archwood-log-tag pedestal units,2500Source. Load tablet into Ritual Brazier, drop exactly one carrier entity and one Iron's book entity in block AABB inflated3, remove other dropped items and activate empty-handed. At completion a successful binder changes book in place and consumes1carrier. Duplicate/full/disabled/uncastable/unexpected inputs refuse without that scroll debit. Inscription Table instead places carrier/book in their slots and uses native action; cancellable inscription event can refuse. See JEI for the physical table and parent ritual build reference.
3. **Cross-cast.** Select the new entry in Iron's wheel and cast safely. Confirm effect and resource delta separately. Bound entries use eight registered proxy IDs (`ars_cross_1..8`); configured cap−1means no extra cap, not infinite native slots. Native slots/capacity and duplicate detection still matter. A proxy's advertised mana0doesn't mean its delegated Ars cast is free. Shortage/refusal and native learning/cooldown conditions remain; payment guide below explains state boundaries.
4. **Alternate item carrier.** Instead of Loom→wheel, craft Spell Transcription tablet: consumed Novice Book reagent, Iron's book-tag+Archwood-log-tag+Source Gem Block pedestals,2000Source. At Brazier use exactly one eligible spell-bearing source entity and one natively blank target entity in inflated3box; activate and collect transformed target. It can carry Ars or Iron's descriptors; reusable sources persist, consumable sources cost1. Right-click in **main hand with ordinary inventory open state**, sneak-right-click cycles entries; offhand/open-container/dead/spectator/sleeping/mismatched descriptor requests reject. This ritual is a distinct optional route and does not award the Loom transcription advancement.
5. **Clear/reuse.** Spell Uninscription tablet: Blank Parchment reagent,Water Bucket+Source Gem+Archwood pedestals,500Source. Place one inscribed target and no ambiguity around Brazier; activate to clear payload. Source/target counts, native spell-container state and conversion differ; don't use it as a promise to duplicate spells or preserve arbitrary foreign components. Exact classifier/blanking and state rules are in carrier companion.
6. **Choose utilities.** Mana Infusion tablet (Blank Parchment reagent;Source Gem Block+Source Gem+Arcane Essence+Archwood;1500Source) completes after60ritualticks and requests500mana default for resolved recipient. Mana Well tablet (Blank Parchment;Source Gem Block+Arcane Essence+Water Bucket+Archwood;2000Source) instead requests2mana/tick default for all intersecting players in box inflated8while active. No universal timer or recurring Source bill is supplied by parent lifecycle; redstone-powered Brazier pauses, loaded relay changes effectcenter, activebreakdoesn't guarantee tabletrefund. Treat these as mana utility choices, not a new tier. All tablet recipes except Uninscription require Iron's loaded. Exact activation/lifecycle/failure distinctions: mana companion.
7. **Specialize optionally.** Equip matched school/regen items, try safe same-school spells, inspect event-based progression/affinity, observe fullness resonance and currently enabled cooldowns. Avoid requiring every recipe or repetitive castcount as mandatory endpoint. Growth is cast-event counts, not XP or kills; optional category cooldown is off by default while fresh bound-proxy cooldown is40ticks. Specific formulas and failure cases are in companions.
