# Design handoffs

Use [the handoff template](../templates/QUEST-COMPAT-HANDOFF.md) to turn supported mechanic research into quests, Tips & Tricks discoveries, compatibility proposals and acceptance tests.

Handoffs should include a **complete progression-to-quest matrix**, including mandatory guidebook onboarding and named guide sections for builds. The [quest walkthrough standard](../../QUEST-WALKTHROUGH-STANDARD.md) requires a player to be able to follow quests + JEI + guidebook from entry to final milestone without an external wiki.

Handoffs are **proposals only**. Editing quests or pack runtime requires a separate owner-authorized implementation task and must follow existing [quest design rules](../../QUEST-DESIGN-RULES.md), [design contract](../../DESIGN.md) and [agent contract](../../../AGENTS.md).
