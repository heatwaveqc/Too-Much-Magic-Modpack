## Open blockers / audits
- **Bigger Reactors (original unavailable), Botania, ProjectE, Apotheosis, Artifacts, Relics, Gateways to Eternity, Deeper and Darker, Starlight/structure mods, magical satchel**: no exact compatible file or full dependency graph has been committed here. Not silently omitted from the decision roster; see manifest pending rows.
- Full transitive dependency graph remains **unverified for noninstalled magic systems**, particularly Astral Sorcery (Curios + ObserverLib reported), Ars Nouveau, Draconic Evolution (Brandon's Core), and rendering mods. Neo Vitae 1.1.53 source declares GeckoLib and Modonomicon as required and both are pinned; its optional Occultism bridge compiles against 1.224.3 while TMM pins Occultism 1.227.0. This is a client/API verification item, not a demonstrated incompatibility. Treat remaining dependency names as candidates, not validated installed IDs.
- Unresolved overlaps: Astral Sorcery sky/rendering with shaders/Embeddium; content/loot balance across Apotheosis/Relics/Cataclysm; acquisition leak paths for ProjectE and banned ring; world-generation interactions.
- **Neo Vitae / Occultism integration audit required:** Neo Vitae 1.1.53 source implements the Sigil of Bound Treasures against Occultism storage controllers and proxies. Its source build declares Occultism 1.224.3 as compileOnly while TMM pins 1.227.0; server co-load passed in B8, but menu opening, access checks and reservation have not been tested. See [`docs/mod-comprehension/mods/neovitae.md`](mod-comprehension/mods/neovitae.md).
- **Neo Vitae Well of Suffering balance audit required:** 1.1.53 source has a separate `well_of_suffering_blacklist`; its `no_sacrifice` tag only changes EV to zero and does not prevent ritual damage. The pinned source snapshot contains no packaged Well blacklist values, while its sacrifice map assigns EV to Wither, Warden, Ender Dragon, Villagers, Wandering Traders, and Iron Golems. TMM's effective datapack tags and repeated-damage/death behavior must be checked before treating these entities as protected or as approved EV sources. This is a source-derived balance risk, not a reproduced in-pack exploit. See the [Neo Vitae profile](mod-comprehension/mods/neovitae.md).
- **JAWR 0.5.39 cauldron Altar Power issue:** all ten pinned `witchery:cauldron_crafting` recipes declare `altarPower: 500`. The upstream 0.5.39 issue report says the cauldron-crafting path neither checks nor consumes the value and reproduces Mutandis without an Altar; its binary analysis lists nine other recipes on the same path. The author says it is fixed in development, but the selected 0.5.39 release has not been confirmed fixed. This may bypass progression and affect the Mutandis → Rowan → Altar opening route; resolve valid Rowan acquisition before considering any cost enforcement. See [JAWR profile](mod-comprehension/mods/witchery-remake.md) and [upstream issue #127](https://github.com/mrsterner/witchery-issues/issues/127).
- **JAWR multiplayer report, version scoped:** upstream issue #130 reports the familiar binding Rite can award the familiar to a bystander rather than the ritual initiator in 0.5.39 on Minecraft 26.1.2. This is not a 1.21.1 test result; include a two-player initiator/bystander boundary test before relying on the rite. See [upstream issue #130](https://github.com/mrsterner/witchery-issues/issues/130).
- **JAWR license metadata differs:** Modrinth lists LGPL-3.0-only but the pinned JAR metadata says `ARR`. The project downloads from its host rather than bundling the JAR; clarify the upstream declaration before any plan to redistribute it.
- **JAWR Forbidden Magic progression predicates remain opaque in the pinned data:** version 0.5.37 adds four chained necromancy advancements with `minecraft:impossible` triggers. Its guide supplies narrative goals, but the artifact's data does not reveal which code events grant each rank. This is a progression-documentation risk, not a demonstrated incompatibility or startup failure. Record rank prerequisites as unverified until matching code or a disposable-world test confirms them; see [Forbidden Magic profile](mod-comprehension/mods/forbidden-magic.md).
- **JAWR Forbidden Magic phylactery behavior remains untested:** the addon defines two 10,000-Altar-Power phylactery craft rites and a separate 500-power binding rite. Exact bind range, eligible soul types, charge consumption and death recovery are unresolved. Do not present its death protection as tested or assume the addon contains the distinct Arca stage in the owner's Archlich target; see [Forbidden Magic profile](mod-comprehension/mods/forbidden-magic.md).
- **Summoning Rituals is co-loadable but currently has no TMM gameplay content:** the pinned framework adds no altar or ritual recipes by default; tracked KubeJS and data files contain no recipe or survival altar acquisition route. The existing quest is informational. This is a content/integration gap, not a demonstrated mod incompatibility. Any future command outputs need review because they execute on the server, and entity sacrifices are killed without normal loot. See [Summoning Rituals profile](mod-comprehension/mods/summoning-rituals.md).
- **Botania Revived 2.0.2 exposes balance-sensitive default modules:** exact JAR/source says Asgard, Creative Crafting and Exploration are enabled by default; the Asgardandelion is documented at 1,000,000 mana per tick, and creative-only items have Terrestrial Plate recipes. Loonium's default behavior produces structure/dungeon loot directly. No tracked Botania config override exists. These are upstream intended features, not a confirmed defect, but they need recipe, config, loot and worldgen review before progression relies on them. See [Botania Revived profile](mod-comprehension/mods/botania-revived.md).
- **Botania Revived Gaia Guardian reward scaling audit:** 2.0.2 source runs the loot table separately for each unique real player who hit the boss, placing that contributor's loot at their position; the final player killer receives a separate Life Essence bonus. Hard mode adds multiple material/rune/relic pools. This may multiply progression rewards with party size and must be checked against TMM's boss-gated economy before designing group quest payouts. Source-derived, not client-reproduced or asserted as a defect. See the [Botania Revived profile](mod-comprehension/mods/botania-revived.md).
- **Botania Revived × Ars Nouveau has an untested native resource bridge:** the exact port implements Source/mana block capabilities, player item-cost conversion, spell deficit fallback, and Mana Cookie regeneration. TMM's Ars 5.13.5 satisfies the port's declared >=5.13.0 floor. Server co-load in B8 does not prove conversion, balance, fractional charge, or multiplayer sync; see the [interaction report](mod-comprehension/interactions/botania-revived--ars-nouveau--mana-bridge.md).
- **EvilCraft 1.2.100 has a source-supported but untested Dragon Survival food interaction:** Rejuvenated Flesh has no vanilla FoodProperties; its own handler checks hunger and stored `evilcraft:blood`, drains 250 mB per completed bite by default, then restores 3 food and 0.5 saturation. The Cave/Forest/Sea data-map selector uses 0/0 synthetic values and retains effects, so client testing must establish that DS allows the item while EvilCraft's cost/restoration handler still runs exactly once. The pair is recorded in [the EvilCraft profile](mod-comprehension/mods/evilcraft.md) and [interaction report](mod-comprehension/interactions/evilcraft--dragon-survival--rejuvenated-flesh.md).
- **EvilCraft faction/worldgen compatibility is unverified:** the mod adds its own werewolf entity and Vengeance Spirits, and adds Dark Ore/dungeons/temples to Overworld plus Infested Nether ore in Soul Sand Valley. No alliance mapping or Tectonic interaction was established in source review; these are test requirements, not demonstrated incompatibilities. The pack's EvilCraft FTB chapter is a one-checkmark placeholder. See [EvilCraft profile](mod-comprehension/mods/evilcraft.md).
- **Occultism miner gate audit required:** matching 1.227.0 source defines ore-miner recipes for Draconium Ore and Uranium Ore using the ordinary occultism:miners/ores tag (weight 142 and 140), plus raw uranium from the Ancient Eldritch Miner (eldritch tag, weight 90). The recipes load only when their Occultism miner and common output tags are nonempty. These are source-confirmed possible gate bypasses, not yet confirmed in the assembled pack: resolve c:ores/draconium, c:ores/uranium and c:storage_blocks/raw_uranium, then test loaded recipes and miner tiers. Compare all miner tables with docs/PROGRESSION.md, including Replica Ore and protected boss drops. The intended miner source is design intent, not an enforced gate yet.
- **Eidolon: Repraised prayer/soul config review:** the 1.21.1-aligned PrayerSpell source declares cooldown default 0 with a 21,000-tick minimum; a prior generated TMM prayer config records the effective value as 21,000, matching the Codex's once-per-day text. Soul Enchanter's source defaults to unlimited uses and enchantments per item (-1). These are configuration/balance review findings, not demonstrated gameplay bugs; exact JAR hash comparison and spell/soul testing remain open. See [Eidolon profile](mod-comprehension/mods/eidolon-repraised.md).
- No pairwise incompatibility has yet been **demonstrated** in a crash. Unknown is not incompatible.
- Potential substitute ideas require explicit approval: *dedicated magical satchel* for first-day carried storage; *different magical structure mod* if a requested dungeon mod lacks a 1.21.1 release. No automatic substitutions.
