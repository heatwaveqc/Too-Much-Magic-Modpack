# Preserve Angler's Hat Treasure ability and modded raw-material fishing

**Decision:** Retain the tier-five **Treasure** upgrade from Reliquified Artifacts' Angler's Hat, including the possibility of fishing up `#c:raw_materials` from compatible mods. Explicit pack override at `kubejs/data/reliquified_artifacts/tags/item/anglers_hat_valuables.json` (nonreplacing merge) preserves the valuable-items pool. Do not copy ATM10's removal of raw materials without an owner decision.

## Authoritative mechanism

- Our selected mods: Artifacts `artifacts-neoforge-13.2.5`, Reliquified Artifacts `1.0.9`, Relics `0.12.5` (all enabled in `manifest/mods.json`).
- Item is Artifacts' `artifacts:anglers_hat`, modified at runtime by Reliquified Artifacts' `AnglersHatItem` and Relics' progression system.
- `AnglersHatItem.constructDefaultRelicTemplate`: `.ability(... "catch")` has `.rankModifier(5, "treasure")` and `treasure_chance` that grows with the relic stat. When active, its `ItemFishedEvent` handler replaces eligible caught fish with a random item from `#reliquified_artifacts:anglers_hat_valuables`; this applies to regular catches and bonus catches.
- Upstream default valuable-item tag contains optional `#c:raw_materials` plus `minecraft:amethyst_shard`, `minecraft:echo_shard`, `minecraft:prismarine_crystals`, `minecraft:nautilus_shell`, `minecraft:heart_of_the_sea`. The shared raw-material tag includes some items from other mods, and actual reach depends on their tag contents loaded in the pack. **Do not claim all possible modded items are fishable**: only tagged materials are eligible for this special replacement.
- This is separate from the hat's extra roll for `BuiltInLootTables.FISHING`, which produces normal vanilla fishing items rather than automatically using lava-specific fishing tables. The upper-tier Treasure rank can convert caught fish into valuables regardless of the provider's native catch table.

## Why this matters: ATM10 removed precisely the raw-material option

All the Mods 10 **8.2** changelog (#4388), `changelogs/CHANGELOG-ATM10-8.1-8.2.md`, explicitly says **Remove raw materials from angler hat loot** and shows `minecraft:item/reliquified_artifacts:anglers_hat_valuables` changed by removing `#c:raw_materials?` while leaving five other entries. This was an **ATM10 pack policy change**, not proof that the underlying Reliquified Artifacts Treasure ability disappeared.

## Our pack's preservation override

```json
{
  "replace": false,
  "values": [
    {
      "id": "#c:raw_materials",
      "required": false
    },
    "minecraft:amethyst_shard",
    "minecraft:echo_shard",
    "minecraft:prismarine_crystals",
    "minecraft:nautilus_shell",
    "minecraft:heart_of_the_sea"
  ]
}
```

This file belongs to the KubeJS-managed data resources at `kubejs/data/reliquified_artifacts/tags/item/anglers_hat_valuables.json` and uses `"replace": false`: it merges with the mod's own item tag instead of disabling or overriding unrelated contents. Duplicate membership is deduplicated by tag resolution. It explicitly guarantees that `#c:raw_materials` and the five vanilla valuables remain eligible even if a future upstream/modpack data change would otherwise omit them, subject to datapack load priority.

## QA and balance

1. With Artifacts + Reliquified Artifacts + Relics enabled, verify the Angler's Hat is converted into a leveling Relic and the fifth rank modifier `treasure` unlocks.
2. Inspect `/reload` tag data for `#reliquified_artifacts:anglers_hat_valuables`: optional `#c:raw_materials` expands to an appropriate nonempty set from the installed modlist, and the five vanilla valuables remain.
3. Fish with and without Treasure enabled, including with Fishing Luck/Improvable Skills, and verify modded raw materials can replace fish at the expected chance. Check source-backed `ItemFishedEvent` behavior at the actual 1.21.1 loader revision.
4. With Gilded lava fishing enabled, verify a raw material generated by the hat doesn't count as a separate native Gilded XP event. Test that the hat's bonus `BuiltInLootTables.FISHING` rolls cannot bypass Gilded lava-fishing authorization.
5. **Balance note:** the raw-material tag can include high-value modded resources. That is an intentional owner choice, not a reason to silently remove the ability; review the *resolved actual tag* and treasure chance if rare modded materials make it too powerful.

## Specific progression-item check (2026-11-16)

**Chaos Shard (`draconicevolution:chaos_shard`): not eligible from currently reviewed default tags.** The 1.21 Draconic Evolution generated item tags include ingots, dusts, nuggets, ores and storage blocks, but do **not** place Chaos Shard in `#c:raw_materials`. The hat's valuables tag likewise does not mention it. This isn't proof of every other loaded datapack: validate the resolved runtime tag before categorically excluding it from a future build.

**Replication's Raw Replica (`replication:raw_replica`): explicitly eligible.** Our enabled Replication 1.21.1-1.2.7 source contains `data/c/tags/item/raw_materials.json` with `replication:raw_replica`, and `raw_materials/replica.json` with the same item. Thus the Angler's Hat can replace a fish with *Raw Replica* after its Treasure upgrade, bypassing the need to mine the ore. The distinct **Deepslate Replica Ore** block/item `replication:deepslate_replica_ore` is in `#c:ores/replica`, not `#c:raw_materials`, and is not directly part of the hat's valuables tag.

**Boss-drop principle:** The hat has no universal "boss drops" or "all modded items" selection. It draws only from its resolved valuables tag; a boss-exclusive item can appear only if deliberately or accidentally tagged there (or added by an override). Current policy is to **retain the full raw-material expansion**, including Raw Replica, per owner request; this is a balance exposure to test, not an automatic exclusion.

## Iesnium eligibility — owner-approved (2026-11-16)

**Keep Raw Iesnium and Raw Replica fishable.** The owner explicitly supports occasional high-tier material catches as a reward for raising the Angler's Hat to its rank-5 Treasure modifier; do not blacklist them for bypassing their normal acquisition routes. The existing `#c:raw_materials` inclusion is intentional, not a bug to "fix."

**Occultism source confirmation (Minecraft 1.21.1):**

- `src/generated/resources/data/c/tags/item/raw_materials/iesnium.json` contains `occultism:raw_iesnium`.
- `src/generated/resources/data/c/tags/item/raw_materials.json` includes `#c:raw_materials/iesnium`.
- The Angler's Hat valuables tag contains `#c:raw_materials`, so Raw Iesnium is eligible for Treasure replacement at rank 5. Its actual probability is determined by Treasure chance and the size of the fully resolved valuables pool; no standalone fixed Raw Iesnium rate is claimed.
- There is no tag change necessary for Iesnium. Keep the whole raw-materials expansion and test representative drops in the next authorized live run; runtime data packs can change the final expanded pool.

## Dragon Survival Elder Dragon Dust — explicit treasure inclusion

Owner-approved 2026-11-16: add `dragonsurvival:elder_dragon_dust` directly to `kubejs/data/reliquified_artifacts/tags/item/anglers_hat_valuables.json` as an optional registry entry (`required:false`). This is the dust used alongside a blaze rod in Dragon Survival's Hot Dragon Rod recipe. It is **not** a member of `#c:raw_materials`, so explicit inclusion is necessary. Retain the parent raw-materials tag (Raw Replica, Raw Iesnium and other modded materials) and the five vanilla treasures. Actual catch chance depends on Angler's Hat Treasure unlocking at Catch rank 5, the stat's chance, and size of the loaded item pool. Validate via live fishing with the upgraded hat; no global raw-material tag is modified.
