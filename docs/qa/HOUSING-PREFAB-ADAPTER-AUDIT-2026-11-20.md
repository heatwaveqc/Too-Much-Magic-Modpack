# Housing provider audit — do the built houses require Prefab Custom Addon? (2026-11-20)

**Result: YES, for the 18 custom houses under the existing architecture. NO for the Generic native Prefab choice.** This is a source/format verification, not a Minecraft client PASS or an endorsement to ship an unreviewed template.

## Exact upstream provider check

- [Prefab Custom Addon](https://modrinth.com/mod/prefab-custom-addon/version/2.7.1) 2.7.1 **is for NeoForge Minecraft 1.21.1**. Project publisher requires Prefab core and LDLib2.
- [Source `ExtensionPackManager.java`](https://github.com/veyne0/prefab-custom-addon-github/blob/1.21.1-main/src/main/java/com/prefab/addon/extension/ExtensionPackManager.java), branch `1.21.1-main` with `gradle.properties` **`mod_version=2.7.1`**, source-only evidence, inspected:
  - lines **342–455**: `scanDirInto` explicitly supports **standalone `.nbt`**, `.schem`, `.litematic` and `.zip`; `loadStandaloneNbtPack` uses the filename stem as construction ID. **Loose NBT is supported**; no mandatory conversion of all houses to ZIP. This validates the QA staging script's format **at source level**.
  - lines **60–108, 204–213**: client base `prefab-extension/` and dedicated-server `prefab-extension/server-cache/` are real search roots, matching proposed staging. Confirm build UI and actual synchronized content under dedicated multiplayer.
  - lines **1263–1302 and 1519+**: standalone NBT may not appear in the `packs` management tab (requires `information/` folder) but is included in the **construction/building list**. Do **not** mistake a missing pack-preview tile for a failed NBT import.
  - Existing house/source audit for 45×63×45 Occult Tower reported volume **127,575**, below source export threshold **1,000,000 cells**, and compressed NBT **129,468 bytes**, below **8 MiB individual server upload** bound. **Still no in-world placement QA** and no guarantee all houses satisfy claim/terrain/current game's version constraints.
- Upstream **Prefab core** supplies built-in house schematics. The present custom-house files are **not wired to its 15 built-in styles** or existing normal house items, and native Prefab has no reviewed route for registering these 18 external NBT structures into the graduation choice selector. A replacement entirely new TMM structure importer could in principle omit Custom Addon, but would introduce a different executable feature, duplicate a maintained importer, and still require server-authoritative entitlement/grant integration.
