### Branch and build discipline

- **Source-locked** means an immutable donor is selected by `manifest/integration-sources.json`; it does **not** mean installed in packwiz, assembled, successfully loaded or client-tested. Do not delete the donor branch while still referenced by any active stream, open PR base/head, or source handoff. The `main` audited SHA-guarded branch-retirement process governs later deletion.
- **Baseline-owned** means the selected source is present in latest `test/full-integration` HEAD. Still check `index.toml`, assembled JAR, runtime resources and gameplay before claiming live inclusion.
- **Blocked** means no safe all-files merge is warranted without repair; keep the PR open, preserve all unique source, and leave the concrete next acceptance task visible. New legacy workflow triggers, removed mod dependencies, and stale `manifest/mods.json` snapshots must not be imported.
- Run **Repository CI, Module CI where relevant, and read-only Integration Preflight** only. Owner authorization is still required separately for Integration Assembly, Server Boot Smoke, Prism QA package, Client Launch and Gameplay Acceptance.
