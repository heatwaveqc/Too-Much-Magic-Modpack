**Status: Source integrated and external Smart Keep Inventory mod SHA-512-pinned. NOT tested in a full NeoForge server or Prism client, and no rebuilt first-party JARs were installed by source reconciliation.**

## Precisely included

- **Newbie / Regular:** first-time new players begin Newbie, saved in existing `PLAYER_MODES` attachment (`copyOnDeath`), projected to the server-managed `tmm_newbie` entity tag. Existing players with nonzero playtime **or an existing joined path** migrate to Regular. Status and operator commands `/tmmnewbie status`, `/tmmnewbie admin graduate <player>`, `/tmmnewbie admin newbie <player>`. Regular cannot self-return to Newbie. Newbie's `/home`, `/sethome`, `/delhome`, `/listhomes`, `/rtp`, `/back` permissions are a command restriction on Regulars; **FTB Essentials commands themselves still require an independently installed provider**, not supplied by this work.
- **Native genuine Elytra:** a synchronized invisible `tmm_progression:virtual_elytra` mob effect authorizes NeoForge's `IItemStackExtension.canElytraFly`/`elytraFlightTick` predicate when Newbie or Regular Monk with unlocked+toggled Momentum Glide. Original vanilla second-jump/glide/pose/collisions remain. Lightweight boost only during genuine `isFallFlying()`, horizontal +0.016/tick with small Monk Glide Control scaling, max +0.026/tick lift, fades to zero at steep pitch, no hovering, Creative flight, bogus Elytra item or fake flight. Registration is merged with later Fortune, Hunter Looting, rare loot and UI mixins, not their older PR #241 snapshots.
- **Any-path/any-species mutual exclusion:** `ProgressionApi.join` denies Newbies, and an optional native transform join veto rejects *any* human Progression path if live five-provider JAWR Vampire/Werewolf, Dragon Survival or Goety/Forbidden Magic lich presence is not verified ABSENT. Five `@Pseudo` native acquisition mixins block **first-time** transformation for a Newbie or already joined *any* human path, including future Gilded. Positive vampire/werewolf/lich levels and non-null Dragon Survival species are acquisition; same native form upgrades, cures and migrated dual-form states remain. JAWR-only Vampire+Werewolf research exception is retained, but human class and supernatural form never combine. Current Dracolich, Archlich, Thermalily, skeleton visual and blood integration are unchanged except their narrow additive guards.
- **MXP gate now actually called:** independent `compat/mxp/MxpService.award` checks Newbie eligibility via reflected, canonical `NewbieMode.canEarnMxp`, plus server scoreboard-tag backstop. If an installed Progression API cannot be resolved it **fails closed**; no ritual, boss, resource transaction or deferred Tyz credit is recorded for a Newbie. No new MXP source or alternate wallet. Growth factor remains configurable default 1.02.
- **Smart Keep Inventory:** exact NeoForge 1.21.1 **1.0.1** JAR metadata is indexed under `mods/smart-keep-inventory.pw.toml`, `side = "both"` for dedicated-server **and** singleplayer, exact Modrinth project `qeGAjqzW` version `JqVOLkFB`, official provider SHA-512 `c9db787e4f4a18bcc659b24e80c63232ac7919dc426fe27952de6f06a31fc67a282c5c50108de18a269411bfc6c8378c220683d0cb2859d83199504c250ac208`. Authoritative NeoForge update info and source metadata are retained. Two indexed JSONs at `kubejs/data/tmm/smart_keep_inventory/condition/newbie.json` and `kubejs/data/smart_keep_inventory/smart_keep_inventory/condition/bosses.json` enable personal keep+XP from `tmm_newbie` tag and disable the mod's stock all-boss protection. **World gamerule `keepInventory` must remain false**, so Regular death uses Corail normally.
- **Tyz Safekept safety:** the actual installed `config/tyzs_skills/custom/skills/keepsake.json` has `active:false`, indexed into Packwiz in addition to the source overlay. This prevents a second skill from independently copying/deleting inventory during Smart Keep / Corail grave handling. Its native Tyz 6.4.2 registry behavior still requires QA.
- **Graduation quest:** exactly **one** addition to the existing 226 total quests (227 now, 188 authored): optional introductory `I'm Ready for Regular Mode`, personal checkmark `544D309000100001`, XP 5 and command reward `tmmnewbie admin graduate {p}`, `permission_level:2`, `team_reward:false`. Existing 226 quest IDs/layouts, 49 Ars Nouveau nodes, alcohol chapter, other XP/rewards/locale remain unchanged. Quest source/resolution/layout and FTB SNBT locale all updated and Packwiz index/root hashes refreshed.
- **Prefab housing** 1.0.9 stays an owner-selected future target in `manifest/mods.json` but `enabled_in_pack:false`; no default house is picked and no unauthorized generated house is granted.
