**Source-to-water conversion:** [EverfullUrnTile.java](https://github.com/Alexthw46/Ars-Elemental/blob/2c433b6a4e6ff5c3b314b5f5442881e0ad2dd0c/src/main/java/alexthw/ars_elemental/common/blocks/EverfullUrnTile.java) runs every **60 ticks (3 seconds)**, checks linked *loaded* targets and Source **within 6 blocks**, and attempts to add up to **1,000 mB water** to eligible fluid handlers (or fill a Botania Apothecary). On a successful fill, charges configured **100 Source** by default per destination attempt. It doesn't create FE, and not every fluid handler is a valid destination; multiple targets can draw separately.

**Fishing loot generator:** [MermaidTile.java](https://github.com/Alexthw46/Ars-Elemental/blob/2c433b6a4e6ff5c3b314b5f5442881e0ad2dd0c/src/main/java/alexthw/ars_elemental/common/blocks/mermaid_block/MermaidTile.java) uses vanilla `BuiltInLootTables.FISHING`, **FISHING_TREASURE**, and **FISHING_JUNK** and a fake-player fishing loot context. [ConfigHandler.java](https://github.com/Alexthw46/Ars-Elemental/blob/2c433b6a4e6ff5c3b314b5f5442881e0ad2dd0c/src/main/java/alexthw/ars_elemental/ConfigHandler.java) defaults Siren Shrine generation to **1,000 Source**, **30 worker progress** per cycle, **1 base item roll**, up to **2 extra diverse-habitat rolls**, and an output stack cap **5** per cycle, with a treasure bonus factor **0.002**. It attempts Source purchase every **80 ticks** when needing power, from blocks within radius **7**. This is separate from mobs and crop harvest.

**TMM loot-gating implication:** If the current/custom **fishing treasure table** includes rare progression parchment, Siren Shrine's direct treasure-loot roll can become another acquisition path, possibly at different effective probability from normal fishing. **Check the planned TMM fishing rarity/gate design statically** before promising that a parchment is exclusively obtainable by actual fishing. This isn't proof that the new parchment is currently installed in Siren output.

### Quest and owner boundary

- **Source lessons** worth adding: Attraction for combining entity and item routing; Repulsion as an optional safer defensive counterpart; Detection to reveal mobs; Tesla as dangerous active defense; Urn Source→water plus external fluid handler; Siren underwater population/loot.
- **Owner decisions:** whether TMM fishing treasure changes should also apply to Siren Shrine rolls; how protected/rare entities interact with attraction/repulsion (especially undead filter); whether Arcane-style boss farming via Source Spawner/Drygmy needs combined tag policy.
- **No standalone gameplay test of native rituals.** Test only effective TMM changes (e.g., custom fishing table/blacklist), and avoid equating effect source, default method cost and charged runtime Source if the needed flag is absent.
