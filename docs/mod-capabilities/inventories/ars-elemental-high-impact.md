The unique Elemental tablets include **Attraction and Repulsion** as environment/entity-routing controls, alongside world growth/forest, detection, pollination, squirrel and Tesla Coil rituals. An existing quest that only acquires a tablet must not be described as verifying actual crowd control or resource throughput.
