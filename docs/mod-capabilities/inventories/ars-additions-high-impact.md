## High-impact Java mechanics — beyond the initial 49-quest pilot

### Source Spawner: *Source paid for real mob spawns*

The [SourceSpawner implementation](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/util/SourceSpawner.java) is **not just another Source generator**; it consumes Source to spawn copies of eligible Mob Jar contents. This is a distinct, late automation surface and **must be included alongside Drygmy and other mob farms**.

- **Entry:** [Source Spawner Apparatus recipe](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/generated/resources/data/ars_additions/recipe/apparatus/source_spawner.json) consumes a Drygmy Charm reagent plus Summon Focus and Conjuration Essence pedestal inputs; it declares **0 Source to craft the block**, *not* 0 Source per mob spawned.
- **Template source:** scans populated nearby Ars Mob Jars in a **Manhattan radius 10** in each coordinate; candidates must hold living entities whose type is not in `ars_additions:source_spawner_denylist`. The default [entity denylist JSON](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/generated/resources/data/ars_additions/tags/entity_type/source_spawner_denylist.json) references both **`#ars_nouveau:jar_release_blacklist`** and **`#c:bosses`**. **Modded bosses not included in those tags may slip through**, depending on actual current TMM tags.
- **Running conditions:** spawner needs a living player within **16 blocks**; initial spawn cadence randomized between **200 and 800 ticks** and defaults to **4 candidate spawn attempts** per cycle. Location spread defaults to 4, class count and collision restrictions apply. Requires real Source in blocks **within five blocks**.
- **Source per successful spawn:** [base formula](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/util/SourceSpawner.java) **200 + 50 × spawned mob's max health** (integer cast), plus **1,000** if category is persistent and **10,000** if mob type is tagged `#c:bosses`. An optional per-entity recipe can override this; no general claim that every NPC costs the same. Extra cost for `#c:bosses` may be moot for types denied by the default tag, but not if a pack changes tags.
- **Actual insertion order:** source attempts to **add the entity to the world first**, **then** withdraws Source; on insufficient Source it removes the spawned entity. This creates a narrow side-effect/event-order surface worth noting for actual TMM event integrations, **not a reason to test all native spawner behavior**.
- **Important balance point:** mob duplication for a small sustainable Source charge can outpace Drygmy and bypass rare mob gating if tags are incomplete. This merits **owner decision on the full denylist**, independently of ordinary Sourcelink rates.

### XP Jar: item voiding → vanilla XP, not XP storage

[XPJar.java](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/item/XPJar.java) extends [base Ars Void Jar](https://github.com/baileyholl/Ars-Nouveau/blob/4d323fba9200c3293a4f4848cf1e0fe70beb7098/src/main/java/com/hollingsworth/arsnouveau/common/items/VoidJar.java). The base Void Jar matches player-filtered pickup items and voids configured items, ordinarily refunding **5 player mana per item**. The **XP Jar overrides the reward**: it grants **one vanilla XP point per two voided items**, carries a 0/1 remainder in its item data, and destroys the input items. **No Source, MXP, experience-orb storage or player skill award is implied.** This is an explicit cost/reward choice, not the Neo Vitae Tome of Peritia.

### Handy Haversack: portable item *transport*, not a backpack inventory

[HandyHaversack.java](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/item/HandyHaversack.java) binds to an actual remote **block item-handler** and records a dimension/position/face plus an item-filter list. It can intercept eligible player item pickups and insert filtered stacks into the bound remote inventory, and right-click inventory interactions can transfer selected stacks. It needs the destination's item handler to be available. It **does not store extra item stacks in a backpack pocket**: the remote inventory holds the items. This makes it a **magic remote-deposit logistics tool**, not the generic extra-inventory backpacks excluded by TMM in prior roster work. Whether to permit cross-dimension or remote chunk-loading effects in TMM is a **policy choice**, not evidence that a generic backpack mod was added.

### Arcane Permanence: default recipe really is disabled

[CommonConfig.java](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/setup/config/CommonConfig.java) defines `chunkloading.ritual_enabled=false` by default, and the [tablet recipe JSON](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/generated/resources/data/ars_additions/recipe/ritual/ritual_chunk_loading.json) has matching `neoforge:conditions`. Its recipe requires Blue Archwood Log, Nether Star, Source Gem, Earth Essence, but is **not available by default**. [RitualChunkLoading.java](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/ritual/RitualChunkLoading.java) and [ServerConfig.java](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/setup/config/ServerConfig.java) define optional player-owned chunk loading: initial **1×1 chunk**, **10,000 Source** at activation and on a default **24,000-tick** daily interval, with the initiating player required online by default. Expanding chunk radius is default disabled. **Do not teach Arcane Permanence as a survival recipe unless TMM explicitly enables it**; source files existing is not recipe activation.

### Additional player-spell and workbench capabilities

- **Mark, Recall, Retaliate** all use **Tier-3 default spell parts** with **160 vanilla XP to learn** each. Their Java **default per-glyph mana** is **Mark 25**, **Recall 50**, **Retaliate 25** (independent of compound spell charge). [Mark](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/glyph/EffectMark.java) records target references in a Reliquary; [Recall](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/glyph/MethodRecall.java) targets them; [Retaliate](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/glyph/MethodRetaliate.java) responds to recent attackers. A Source crystal alone does not grant universal teleportation or persisted chunk access. Source version's Unstable Reliquary target cost config is player **1,000**, entity **250**, position **50** default durability, with a default **300s** Marked effect duration; these costs are *reliquary durability*, not casting mana or Source.
- **Bulk Scribing**: [BulkScribingRecipe.java](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/recipe/imbuement/BulkScribingRecipe.java) adds a true Imbuement Chamber recipe that can imprint compatible spells on supported scribable items. Its `getSourceCost` uses the **spell's cost** via its caster, so don't assume free mass spell transcription.
- **Wixie Enchanting Apparatus**: a distinct addon [EnchantingWixieCauldronTile.java](https://github.com/Jarva/Ars-Additions/blob/91f102a90dc058cf40e4eac5a67a881e48b856b4/src/main/java/com/github/jarva/arsadditions/common/block/tile/EnchantingWixieCauldronTile.java) extends the base Wixie Cauldron for supported apparatus recipes. It is different from ordinary native Wixie potion crafting and absent from the three Additions pilot quests.
- **Locate Structure**: one separate ritual plus **15 named recipe target definitions** including Stronghold, Ancient City, End City, Wilden Den and Arcane Library. It is a capability for **detection/information and exploration**, not an ore generator. Existing quest coverage only mentions other Additions remote items.

## Revised quest and balance handoff

1. **Code-ready documentation**: add Source Spawner and XP Jar lesson candidates, Handy Haversack remote deposit/filter tutorial, optional Bulk Scribing/Charm charging and Locate Structure branch; no native feature testing required.
2. **Owner-level constraints**: choose Source Spawner boss/rare/default tag policy; distinguish Handy Haversack magic remote inventory from prohibited generic backpacks; decide whether chunk-loading ritual should remain default recipe-disabled.
3. **TMM-specific testing only**: when a pack denylist/recipe/config/quest detector is changed, test precisely that boundary and confirm it does not silently evade intended boss/rare material gates. Do not schedule generic native functionality regressions.
