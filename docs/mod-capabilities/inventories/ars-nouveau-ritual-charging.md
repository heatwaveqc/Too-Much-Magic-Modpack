# Ars Nouveau 5.13.5 — ritual Source charging and economy (Java source audit)

**Research objective:** Differentiate **tablet crafting**, **activation**, **actual completed work**, and **Source debit**. Source is block-carried, not player mana, FE or TMM MXP. Native functions do not require standalone game tests unless TMM changes an affected path.

## Parent ritual charge contract (source verified)

1. [AbstractRitual.java](https://github.com/baileyholl/Ars-Nouveau/blob/4d323fba9200c3293a4f4848cf1e0fe70beb7098/src/main/java/com/hollingsworth/arsnouveau/api/ritual/AbstractRitual.java) defaults `getSourceCost()` to **0**; `consumesSource()` means **cost > 0**. It keeps persistent `needsSourceToRun` state; `takeSourceNow()` sets that flag and requests a debit.
2. [RitualBrazierTile.java](https://github.com/baileyholl/Ars-Nouveau/blob/4d323fba9200c3293a4f4848cf1e0fe70beb7098/src/main/java/com/hollingsworth/arsnouveau/common/block/tile/RitualBrazierTile.java) checks `consumesSource && needsSourceNow`, then calls `SourceUtil.takeSourceMultipleWithParticles(pos, level, 6, cost)`. On success it clears the pending flag; on failure it delays retries **20 ticks** and skips the ritual work tick.
3. Consequently, a per-class `getSourceCost()` is an **amount per requested effect/batch/refresh**, not necessarily per second, per entity, or once on ritual start. Several ritual classes **perform the first effect before marking Source as required for continuation**, so budget and depletion order matters.
4. Other ritual sub-processes might use separate Source work queues (the Conjure Island descriptions say they require Source as blocks are generated). A missing `getSourceCost` override means **zero for the standard Brazier event-debit path**, not necessarily zero total Source consumed by every subordinate implementation.
5. The **24-class runtime table** is [here](ars-nouveau-ritual-operations.md), and [tablet ingredient recipes](ars-nouveau-ritual-tablets.md) remain a different question.

## Farm, Source and progression consequences

- **Disintegration ≠ Drygmy ≠ Vitalic:** Disintegration converts monster entities to *experience gems* **without normal loot**; Drygmy produces renewable loot-table items and reduced XP-gem output without killing; Vitalic converts breeding/death events into block Source. They need different quests, output safeguards and resource accounting. Vanilla XP items do not create TMM MXP.
- **Sanctuary may suppress nearby natural hostile mob farms**; its spawn listener specifically tests NATURAL spawn type (plus a village siege handler). Other types are not automatically affected by the same check.
- **Fertility + Vitalic** is an interesting renewable Source pairing. Do not assert net positive on naive arithmetic: 600 Source per eligible breed event versus a Fertility 500 Source batch requires checking events, caps, distance, throughput, both operating states, and whether generation itself was paid by previous output.
- **Restoration villager discounts** are a genuine Ars trade/economy capability, beyond jarring Occultism Traders.
- **Testing scope:** review TMM changes to loot/entity blacklists, ritual/Source adapters or new FTB detectors, not intact upstream ritual effects. A source-level native edge or mismatch can be documented without scheduling a pack regression suite.
