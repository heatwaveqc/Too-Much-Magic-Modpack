# Neo Vitae 1.1.54 — 26 native Alchemy Array effect-item implementations

**Pinned/version evidence:** exact upstream source `501a8d6a0431ed8aeb19e18be2e83f1856f29a21` [1.21.1 source](https://github.com/breakinblocks/NeoVitae/tree/501a8d6a0431ed8aeb19e18be2e83f1856f29a21), declared 1.1.54 = current TMM Modrinth pin version. All **26/26** registered `neovitae:array_*` effect items are mapped to their corresponding `AlchemyArrayEffect*.java` class below. The existing [48 generated Array crafting recipes](neovitae-array-recipes.md) record `baseinput`, `addedinput`, output and explicit EV fields; a craft-recipe output is **not** automatically the same as a persistent placed array. No replay of that 48-row recipe extraction. [Registered inventory](neovitae-operations.md), [source guide](https://github.com/breakinblocks/NeoVitae/blob/501a8d6a0431ed8aeb19e18be2e83f1856f29a21/wiki/Alchemy-Arrays.md).

**Source activation:** ordinary arrays are formed with Scribe Tool on suitable block; recipe places base then catalyst. Where the result is an **effect item**, its dedicated Java class runs `update` or entity collision callbacks through `AlchemyArrayBlockEntity`, may remember an owner `Binding` and send real EV debits to that player's `Anima`. Do not infer zero cost from missing `ev_cost` JSON property; either class or configured runtime/default could charge. [Effect base](https://github.com/breakinblocks/NeoVitae/blob/501a8d6a0431ed8aeb19e18be2e83f1856f29a21/src/main/java/com/breakinblocks/neovitae/common/alchemyarray/AlchemyArrayEffect.java) and [Array block entity](https://github.com/breakinblocks/NeoVitae/blob/501a8d6a0431ed8aeb19e18be2e83f1856f29a21/src/main/java/com/breakinblocks/neovitae/common/blockentity/AlchemyArrayBlockEntity.java).

## Source honesty and quest branch implications

- **Passive vs use/one-shot:** the collision pads, Miner, Furnace, Collection, Light, Vortex and Fountain are infrastructure/area effects. Day/Night/Rain and Loyal Friends are timed single actions. Don't give credit merely for *holding* an array effect item and do not confuse output item IDs with an actually active placed array.
- **Strong discrete proof:** a successfully smelted/delivered output, fluid tank delta, mined physical block, changed redstone level, pet teleport, growth or actually moved entity verifies function. Vanilla inventory tasks demonstrate only item acquisition. A dedicated Neo Vitae event/advancement hook or custom adapter would be needed for actual first-use credit.
- **Energy identity:** `liquified_experience` exchanges vanilla **XP points in an Experience Tome ↔ fluid experience**, not MXP, Spiritus, Anima or guaranteed abstract ProjectE EMC conversion. Correct potential TMM rate only after effective config and economy audit.
- **Effect consumer gap:** `Imprisonment` and `EnderSever` effect classes themselves contain no substantial per-tick operation; their external event-driven consumers **still require explicit class trace**. This is an honest finite gap, not licence to claim they do nothing or have proven native efficacy.
- **Pack policy:** Endless Fountain creates ordinary renewable water and other arrays deliberately perform powered production; these are not native creative-tier/debug items targeted by [no-creative-survival policy #596](https://github.com/heatwaveqc/Too-Much-Magic-Modpack/issues/596).
