## Spirits are nine typed items, not FE or personal Mana

Native spirit item types: Sacred, Wicked, Arcane, Eldritch, Aerial, Aqueous, Earthen, Infernal, and **Umbral**. IDs use `malum:<name>_spirit`. Spirits are material ItemStacks harvested through soul-exposed mob death, stored in player inventory, jars, pouches and station item slots, **consumed as typed recipe inputs**. Rare Umbral is part of the separate Weeping Well/Void branch, not a general equivalent for all common spirits. Native spirit drops are data-driven and affected by the soul-exposure and soulless-spawner settings. No identity with ProjectE EMC, Neo Vitae EV, Botania Mana, vanilla XP or TMM MXP is implied.

## Exact required pole patterns and activation

Totem is an upright stacked structure: Totem Base at bottom, **one engraved Spirit per pole in exact order bottom→top**. The registry's `SpiritRiteType.matches` checks the **ordered exact pole list** and that the base is normally **Runewood** or corrupted **Soulwood**. The native [builder](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/core/systems/rite/SpiritRiteTypeBuilder.java) establishes **minor = Arcane, Aspect, Aspect (3 poles)**; **major = Eldritch, Arcane, Aspect, Aspect (4 poles)**; special = **five Arcane** (different base produces different effect). Aspect-specific ordinary rites require Runewood and alternatives require Soulwood. Place carved poles above base, use base to assemble: source [TotemBaseBlockEntity](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/common/block/curiosities/totem/TotemBaseBlockEntity.java) advances one pole each 20 ticks, searches matching rite, fails to inactive if no match, then runs its effect when the saved timer elapses. Default [SpiritRiteEffect](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/core/systems/rite/effect/SpiritRiteEffect.java) cooldown is **100 ticks (5 seconds)** unless overridden. There is no **general ongoing spirit-per-pulse drain** in the core implementation; the spirits are part of the inscribed structure and effects have their own material/target conditions.

**Entity targeting default:** [SpiritRiteEntityEffect](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/core/systems/rite/effect/SpiritRiteEntityEffect.java) picks up to **two eligible LivingEntity instances within an eight-block AABB** and dispatches traveling activators per successful pulse. Standard potion-affecting rites [SpiritRitePotionEffect](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/core/systems/rite/effect/SpiritRitePotionEffect.java) apply **3,000 ticks, amplifier 1**, with specialized exceptions; ordinary minor positive effects are not innate permanent player skills. Block effects use directional activators and geometry/physical eligibility, not an inventory output table.

## Quest and integration cautions

- **Rending is not summoning.** The Java field `RITE_OF_RAISING` and class `MonsterRaisingEffect` map to registered `malum:rite_of_rending`: the code damages low-health Monsters; the questbook must not teach this as a pet summoning ability.
- **Undirected is a world transformation**, and Unchained requires a tagged target catalyst plus one of **70** `unchained_transmutation` recipes. Warn about terrain changes and don't require transformation as the first safe tutorial.
- **Nurturing/Lust/Culling are separate**: child growth, adult breeding and selective herd reduction (minimum per-type population 20), not single interchangeable animal magic.
- **Rite effect vs rune effects** differ: SpiritRitePotionEffect applies 3,000-tick amplified status while rune application paths commonly apply 600 ticks/amplifier 0; no source-backed blanket equivalence.
- **Entity targets and output:** entity rites choose two, not every mob within radius at every pulse. Block rites can modify the world and must be checked against claims/permissions before release testing.
- **Endgame creative policy #596:** do not automatically blacklist native runewood/cobblestone generation or growing systems merely because they are renewable. Review only items actually creating unrestricted zero-input infinite outputs and their survival acquisition.
