# Malum 1.8.2 — all 24 Runeworking Rune classes, native effects and Curios interfaces

**Immutable source:** [Malum 1.8.2 exact commit](https://github.com/SammySemicolon/Malum-Mod/tree/03b743a37f3eeb0cc7f4364f0730e1f135f78408). All **24/24 actual native Java Rune classes** were individually inspected and matched to **24/24 generated `runeworking` JSON recipe paths**. The native classes comprise eight Totemic, eight Miracle and eight Madness Runes, with distinct Curios type requirements. The full JSON recipe quantities were inspected for representative examples but not all 24; the exact source links are in the table. The separate Gaze addon advertises eight more Runes, not counted or inspected here.

## Equipment behavior and Rune classes

- **Totemic Runes (8)** are wearable forms of eight lesser-Rite potion effects. [`TotemicRuneCurioItem`](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/common/item/curiosities/curios/runes/TotemicRuneCurioItem.java) invokes `applyRuneEffect` every **5 ticks** while equipped. [`SpiritRitePotionEffect`](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/core/systems/rite/effect/SpiritRitePotionEffect.java) applies a **600-tick amplifier-0** status from the Rune, versus **3000-tick amplifier-1** status from a physical Totem Rite. This is an ongoing worn buff, not a permanent Geas.
- **Miracle Runes (8)** supply situational defense, healing, Soul Ward and Scythe capabilities. **Madness Runes (8)** adjust maximum HP, silence, conditional resistance, Scythe sweeps, staff charge, effect duration and movement. Some effects are attribute modifiers, others require specific events. None is proof of creative-mode invulnerability or a generic FE/Mana conversion.
- **Curios slot types:** Totemic uses `MalumTrinketType.TOTEMIC_RUNE`; Miracle uses `MalumTrinketType.RUNE`; Madness uses `MalumTrinketType.VOID_RUNE`. Verify actual loaded Curios slot counts and TMM modifier interactions before claiming runtime behavior.

## Representative exact rune costs and quest proofs

- [Rune of Burning Fervor](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/runeworking/rune_of_burning_fervor.json): **4 Runewood Planks** as the Runeworking primary input plus **32 Infernal Spirits**, one result. A practical Totemic starter quest should observe the buff *while equipped*, not mere Rune possession.
- [Rune of Vitality](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/runeworking/rune_of_vitality.json): **4 Tainted Rock** and **16 Sacred Spirits**, one output; equipping adds +20% Healing Multiplier. Its actual healing effect requires a healing event after that.
- **Geas interop:** The [Pact of Rune Exploitation](malum-1.8.2-geas-effects.md) adds **two transient Rune Curios slots** at the price of progressive defenses/healing penalties, rather than upgrading each Rune's crafting tier. A future TMM Path could modify skill rates, but these are native *equipment capacity and effects*, independent from MXP.
- **Quest detection:** To prove a Rune works, observe actual status effect, attribute or event outcome. Rune ownership alone is an honest proxy only if labeled as possession, not a verified damage/health buff. No real FTB tasks or JNI/Curios detector were written here.
