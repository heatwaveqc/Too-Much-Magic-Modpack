# Malum 1.8.2 — all 24 Runeworking Rune classes, native effects and Curios interfaces,,**Immutable source:** [1.8.2 exact commit](https://github.com/SammySemicolon/Malum-Mod/tree/03b743a37f3eeb0cc7f4364f0730e1f135f78408). All **24/24 actual Java Rune classes** were individually read, with the **24/24 generated `runeworking` JSON recipe source links**. They are **eight Totemic, eight Miracle, eight Madness**; these are three distinct Curios rune types, not universal interchangeable effects or generic permanent skill-tree perks. Input/source links are exact; only first examples have parsed quantity totals, so **do not infer equal ingredient cost across 24**. The separately selected Gaze addon's **eight more advertised Runes are not counted or inspected** here.,,## Core active Rune behavior,,- **Totemic Runes (8)** are equipment-based versions of eight specific **lesser Rite potion effects**. Source [TotemicRuneCurioItem](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/common/item/curiosities/curios/runes/TotemicRuneCurioItem.java) calls `applyRuneEffect` every **5 ticks** while equipped; [SpiritRitePotionEffect](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/core/systems/rite/effect/SpiritRitePotionEffect.java) applies the selected status for **600 ticks at amplifier 0** (higher-tier normal physical Totem rites apply **3000 ticks amp1**). Thus the rune gives an **ongoing worn buff**, distinct from a physical 3-pole Rite's two selected targets and from a permanent Geas.,- **Miracle Runes (8)** augment defenses, healing, Soul Ward and Scythe situational combat. **Madness Runes (8)** change max health, silence, resistances, sweep ratio, cast charge and effect durations. Several grant direct static Curios attributes; others use event hooks requiring specific damage/potion triggers. These have no generic FE/Mana/Spirit cost every tick in the inspected base item classes, but equipping and source recipes require Rune slot and material prerequisites.,- **Gear slot taxonomy:** Totemic uses `MalumTrinketType.TOTEMIC_RUNE`, Miracle uses `MalumTrinketType.RUNE`, Madness uses `MalumTrinketType.VOID_RUNE` (base classes [Totemic](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/common/item/curiosities/curios/runes/TotemicRuneCurioItem.java), [Miracle](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/common/item/curiosities/curios/runes/miracle/MiracleRuneCurioItem.java), [Madness](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/common/item/curiosities/curios/runes/madness/MadnessRuneCurioItem.java)). ## Representative exact rune costs and quest proofs

- [Rune of Burning Fervor](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/runeworking/rune_of_burning_fervor.json): **4 Runewood Planks** as the Runeworking primary input plus **32 Infernal Spirits**, one result. A practical Totemic starter quest should observe the buff *while equipped*, not mere Rune possession.
- [Rune of Vitality](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/runeworking/rune_of_vitality.json): **4 Tainted Rock** and **16 Sacred Spirits**, one output; equipping adds +20% Healing Multiplier. Its actual healing effect requires a healing event after that.
- **Geas interop:** The [Pact of Rune Exploitation](malum-1.8.2-geas-effects.md) adds **two transient Rune Curios slots** at the price of progressive defenses/healing penalties, rather than upgrading each Rune's crafting tier. A future TMM Path could modify skill rates, but these are native *equipment capacity and effects*, independent from MXP.
- **Quest detection:** To prove a Rune works, observe actual status effect, attribute or event outcome. Rune ownership alone is an honest proxy only if labeled as possession, not a verified damage/health buff. No real FTB tasks or JNI/Curios detector were written here.
