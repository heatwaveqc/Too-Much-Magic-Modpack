# All seven Ars addons — exact source JSON recipe-discovery inventory (second pass)

**Frozen source revisions and installed version alignment:** The seven specific addons pinned in TMM's `test/full-integration/manifest/mods.json` have source trees indexed below. This is a comprehensive directory discovery of **`data/<addon namespace>/recipe/**/*.json`** in these seven source snapshots, not a compiled-JAR parity guarantee and **not** a claim that any recipe is enabled after TMM scripts/datapacks. Several addons are built against earlier Ars core API versions; preserve exact dependency gap in the [addon mechanics matrix](ars-nouveau-addon-family.md).

A listed JSON filename is **not** a demonstrated unique player capability. A deeply tiered armor set can have dozens of shaped or upgrade variants. [The 29-axis Ars dossier](../mods/ars-nouveau.md) and [quest gap map](../mods/ars-nouveau-quest-map.md) separate those from actual progression. The **source path links here are immutable**. A consumer wanting ingredients or `sourceCost` must read the JSON rather than infer it from a name. The two recipe-less adapters are explained after the inventory.
