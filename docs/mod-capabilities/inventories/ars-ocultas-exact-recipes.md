## Gameplay and gating implications

- **Spirit Attuned Gem** is an optional Ars Enchanting Apparatus acquisition recipe; it **does not replace** the Occultism binding tier ladder.
- **Silver ↔ gold** is one-way per recipe, two recipe definitions, 2,000 Source per successful ingot operation according to the established addon source; the input metal plus essences/gem still have material costs.
- **Sacrificial Altar:** crafting Source cost and runtime **5,000 Source per fulfilled pending sacrifice/item-use flag** are **different transactions**. The implementation is source-confirmed to signal a Golden Sacrificial Bowl without consuming its stored jarred entity or matching item. Treat as a serious **owner gating decision**, not a demonstrated client exploit or a native mod test obligation.
- **Marid tier-4 storage stabilizer:** inspect Occultism dictionary/binding requirements (including Iesnium, bound Marid and correct pentacle). A generated source recipe path is not a legitimate way to skip those materials.
- **Soul Gem ↔ Mob Jar** is **event/handler logic**, not one of the five recipe files. Existing source exposes the possibility of entity-data removal before a later deny check; only an actual pack integration or observed failure justifies scoped runtime QA.
