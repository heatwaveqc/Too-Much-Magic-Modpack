## Player capability and resource interpretation

- **Spell Loom + Blank Scroll:** obtains real Iron's spell carriers from Ars book/parchment data, then Iron's Inscription Table or separate **Spellbook Binding** ritual lets the Iron's wheel cast. New scroll appearance/name is not equivalent to paying future spell mana.
- **Generic Spell Transcription** is a **different** ritual: source-bearing Ars or Iron's spell + blank target yields a right-click cross-casting item; **Spell Uninscription** clears one target. Distinguish both paths in the quest.
- **Mana Infusion / Mana Well** are block Source-to-**player mana** utilities, but the amount and destination pool depend on addon server settings, native ritual lifetime, and whether the player is in the area. From 3.3.5 source profile, Well default **2 mana/tick** per eligible player when active, 8-block AABB reach; do not infer infinite duration or guaranteed net Source profit from one tablet.
- **Owner operational clarification (2026-11-21):** cross-mana is reported to **already work** in TMM. Mode config offers `iss_primary`, `ars_primary`, `hybrid`, `separate`, `disabled`; upstream fresh default `iss_primary` is **not proven current TMM effective enum**. That exact enum is a documentation detail rather than a new design hold; do not propose rebalancing solely because the static source supports multiple modes. Other independent damage school-power, persistent practice-count, resonance and cooldown rules can remain active when mana-unification is disabled.
- **First-party concern:** an MXP reward handler may trigger on actual spell/ability cost expenditure; ensure a cross-cast does **not** double-award when both parent cost adapters see the same event. This is a TMM implementation/integration question, not a claim that addon XP grants MXP by itself.
- **No native regressions:** only test modified TMM config/bridge or new FTB detector. The exact source recipe links are reusable quest instructions, not an authorization to reproduce all 3.3.5 upstream tests.
