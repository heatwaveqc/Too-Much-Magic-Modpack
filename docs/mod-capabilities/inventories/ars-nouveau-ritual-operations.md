# Ars Nouveau 5.13.5 — source-class ritual operation inventory

**Exact scope:** 24 native Java ritual implementations found in [the 5.13.5 source ritual directory](https://github.com/baileyholl/Ars-Nouveau/tree/4d323fba9200c3293a4f4848cf1e0fe70beb7098/src/main/java/com/hollingsworth/arsnouveau/common/ritual). This is a **code-class catalog** in addition to [all 24 tablet recipe JSONs](ars-nouveau-ritual-tablets.md). A class's optional `getSourceCost` override returns an **expression**, not a measured operation, and its absence must **not** be interpreted as guaranteed zero (may inherit from base ritual). Activation/cycle semantics depend on the parent base class and ritual state, which are not completely audited here. `setNeedsSource(true)` in a class is evidence it requests ongoing Source in some path.
