# Malum 1.8.2 — native starter walkthrough, machine contracts and advanced production

**Evidence:** immutable [native 1.8.2 source](https://github.com/SammySemicolon/Malum-Mod/tree/03b743a37f3eeb0cc7f4364f0730e1f135f78408), declared version matches current TMM `malum-1.21.1-1.8.2.jar`. Each representative recipe here was opened/parsed, including its actual tagged inputs and typed Spirit item counts. [All 938 source recipe paths](malum-1.8.2-special-recipe-paths.md) are separately indexed in generated specialized, ordinary and handwritten ledgers; **path discovery ≠ all 938 parsed recipe contents**. No live client, JAR byte comparison, effective pack recipe test, or FTB task implementation is claimed.

## First survival steps — the shortest evidenced source path

1. **Refine Soulstone:** Mine `malum:raw_soulstone` or its registered source ore and **smelt 1 Raw Soulstone → 2 `malum:refined_soulstone` in 200 ticks (0.25 vanilla smelting XP)**. [JSON](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/soulstone_from_raw_smelting.json). Exact ore location/harvest tier may vary by TMM's Tectonic; inspect JEI/world rather than assume it spawns at a particular Y.
2. **Open the guide:** One `minecraft:book` + one refined Soulstone shapeless → `malum:encyclopedia_arcana` [JSON](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/encyclopedia_arcana.json). Independently, native config `common/codex.enableCodexDrop=true` and exposed-soul/undead kill may award the guide to the first eligible killer; that is an **alternative**, not mandatory, and subject to saved player progression. [source](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/core/handlers/SoulHarvestHandler.java).
3. **Craft the Crude Scythe:** shaped `XXY /  #X / #  ` (where `X=#c:ingots/iron` **3**; `#=#c:rods/wooden` **2**; `Y=malum:refined_soulstone` **1**) → `malum:crude_scythe`, base item **500 durability**. [JSON](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/crude_scythe.json). This is not a Soul-Stained Steel Scythe; it is the practical introduction to Soul Exposure and reaping.
4. **Expose then reap a soul:** Scythe/soul damage interacts with [LivingSoulData](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/common/data/attachment/soul_data/LivingSoulData.java), which tracks `exposedSoulDuration`, set to **200 ticks (10 seconds)** by `setExposed()`. The target must die while exposed and not be soulless; on `LivingDeathEvent` [source](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/core/handlers/SoulHarvestHandler.java) drops item-typed Spirits based on data, not random generic FE. Native `common/spirit/spawner.lameSpawners=false` means soulless-spawner blanket suppression is **off by default**; a future TMM blacklist may modify effective drop eligibility. Demonstrate a normal qualifying hostile kill and collect actual Spirits, not just raw XP.
5. **Make a first Spirit Altar:** shaped ` Y /ZXZ/XXX`: **4 Runewood planks (`#malum:runewood_planks`), 1 refined Soulstone, 2 Gold ingots (`#c:ingots/gold`)** → `malum:spirit_altar`. [JSON](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/spirit_altar.json). For **first effect**, one Gunpowder at altar center plus **one Arcane Spirit** makes one Hex Ash via [JSON](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/spirit_infusion/hex_ash.json). The result drops above altar as an ItemEntity; mere altar possession is insufficient quest proof.
6. **Next craft station and material:** Soul-Stained Steel is an alternate native material: central one Iron Ingot + 4 Refined Soulstone extras from nearby pedestals + **3 Wicked, 1 Earthen, 1 Arcane Spirits** → one `malum:soul_stained_steel_ingot` [JSON](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/spirit_infusion/soul_stained_steel_ingot.json). The upgraded Scythe uses Crude Scythe plus 4 steel ingots/2 Hex Ash/4 refined Soulstone and **16 Earthen +8 Wicked +8 Arcane**, preserving item component data (`carryOverComponentData:true`). [JSON](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/generated/resources/data/malum/recipe/spirit_infusion/soul_stained_steel_scythe.json).

## Resource and economy distinctions

- **Spirits** are eight ordinary elemental/ethical types plus rare Umbral; counts in recipe JSON are actual **consumed item quantities**. Spirit jars and pouches are typed item storage, not a numerical universal Spiritus tank or FE.
- **Soul Ward** is a separate player/creature defensive attached charge. [CommonConfig](https://github.com/SammySemicolon/Malum-Mod/blob/03b743a37f3eeb0cc7f4364f0730e1f135f78408/src/main/java/com/sammy/malum/config/CommonConfig.java) native defaults when active: physical damage multiplier **0.7** (30% reduction), magic multiplier **0.1** (90% reduction), recovery cadence **100 ticks per point** before skill attributes; it isn't a permanent infinite immunity or a backpack resource. Its capacity is an attribute and starts **0** in `MalumAttributes.SOUL_WARD_CAPACITY`, granted by gear/geas/etc.
- **Geases** are persistent attached player passives constrained by `GEAS_LIMIT` (native base **2**, attribute bounded **0..8**) not TMM MXP or default character Path. Soul Brazier applies them; no 36-crafted Geas-item output line.
- **Metal nodes** are material production but inspect Node use and default tag availability before labeling free ore creation. The source exists, some recipes gated on available nugget material tags. TMM should reconcile EMC/magic resource values and uranium supply policy, not suppress all Spirit Crucible recipes.
- **Pouches:** Source `malum:soulwoven_pouch` and `malum:ravenous_pouch` are bundle-like generic item storage, not just Spir­its. Both `getStorageSize()` display **512** maximum weight slots. Weight math allows Soulwoven roughly **64 normal stack-64 items** or **512 tag-efficient items**, Ravenous **512 ordinary stack-64 items** at weight modifier8. Number of unique occupied slots is not fixed at 512. They accept broadly `canFitInsideContainerItems()`-eligible items, meaning they conflict with TMM's generic-backpack exclusion; explicit owner policy review before survival reward/progression. Nesting must obey native container-item eligibility; not proven safe to allow unrestricted embedding.
- **No runtime test:** Progression recipe accessibility, actual loaded worldgen and pack-awarded objectives, usable Gaze items, survival client performance, FTB per-player detectors and station acceptance remain independent.
