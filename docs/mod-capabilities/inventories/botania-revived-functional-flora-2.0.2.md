Source values below are *defaults or class constants*, not blanket player QA PASS.

These are the **upstream default configured rates**, not the class `DEFAULT_COST` or `DEFAULT_RANGE` constants. Exact TMM runtime config may override. ## Source-backed cross-mod acceptance boundaries

- **Ore economy:** Orechid/Orechid Ignem weighted recipe output distributions require a live pack **effective datapack/registry census** to confirm no early Draconium/Replica or boss-gated bypass. Source code shows the mechanism; it cannot prove which TMM JSONs shipped or were overridden.
- **Loot economy:** Direct Loonium item output is repeatable and driven by loot tables, with **only a narrow upstream blacklist**. TMM's separate player loot, Shop, ProjectE and boss gates need actual output inclusion review; do not ban all Loonium loot from source speculation or mark exploit PASS.
- **Automation and ownership:** Hopperhock inventories and Rannuncarpus placement are native, but TMM bag-in-bag restrictions, claims, Worldgen and Curios ownership are separate integration policies. A source-level capability does not automatically grant an unrestricted bypass.
- **Quest detection:** An item acquired through hopper pickup, trade, Loonium loot, another player or ProjectE is not proof of successful flower use. Use source events where reliable; otherwise transparent manual use checkpoint and tangible output after the action. FTB implementation remains another workstream.
