# Botania Revived 2.0.2 — port modules and survival accessibility audit

**Provenance:** exact pinned Botania Revived 2.0.2 source [5f803227](https://github.com/Velron-Devs/Botania-Revived/tree/5f803227d484598da1f1093a91d5d7cf5cf9600d); TMM baseline `test/full-integration` does not have a tracked `config/botania-common.toml` or `defaultconfigs/botania-common.toml`. **Status:** default-source conditional **not confirmed effective runtime**; native module registration/recipes may be altered by generated config or datapack overrides in a player world.

### Module loading and identity

`BotaniaModules` enumerates `botania_extras`, `magic_skies`, `exploration`, `creative`, `asg`, and `sophisticated`. It reads `config/botania-common.toml` **at startup** for `[modules]` identifiers. `BotaniaModule.enabledByDefault()` is true unless a specific module overrides; module content is skipped when disabled or dependent mods absent. Changes require a restart, not datapack reload. [source](https://github.com/Velron-Devs/Botania-Revived/blob/5f803227d484598da1f1093a91d5d7cf5cf9600d/src/main/java/velrondevs/botania/module/BotaniaModules.java) / [source](https://github.com/Velron-Devs/Botania-Revived/blob/5f803227d484598da1f1093a91d5d7cf5cf9600d/src/main/java/velrondevs/botania/module/BotaniaModule.java). **Never infer modules are disabled merely because TMM has no checked-in config.**

### Design judgment for owner (one focused flag, not a hold on research)

**The Creative Mana Pool is the serious unlock to evaluate**, not Asgardandelion. It bypasses all late Mana generation once Gaia Life Essence/Terrasteel/1m stored Mana have been assembled. This is not directly an Occultism→Endgame lock, and alternate magic routes are owner-approved, so source research should not silently ban it. Decide only whether the **post-Gaia infinite-Mana option is intentional**; if yes, document it as a real Botania endgame capstone, not a loophole; if no, integration should disable the `creative` module or override only relevant native Terra Plate recipes, preserving other capabilities as desired. TMM research branch makes **no runtime change** or speculative nerf.

### Botania Extras — independent port-exclusive generator

The default-enabled `botania_extras` module registers **Crysanthermum** (`botania:crysanthermum`), an additional *generating flower* outside the 43 core-family base count. Its [source block entity](https://github.com/Velron-Devs/Botania-Revived/blob/5f803227d484598da1f1093a91d5d7cf5cf9600d/src/main/java/velrondevs/botania/module/botaniaextras/block/CrysanthermumBlockEntity.java) consumes eligible nearby stone-type blocks to alter its **temperature** within −8…+8 and generates Mana from matching the **local biome temperature target**: checks each **5 ticks**, base **5 Mana per pulse** modified by closeness, buffer **8,000 Mana**, stone-feed cooldown/history and environmental tuning. This is a third distinct route alongside Asgardandelion and standard generators; no permission to equate it to Thermalily. The module also registers **Dendric Suffuser** tree-suffusion crafting, 3 biome/weather-themed rods, additional woods, fuels and conditional world content. Exact crafted inputs stay in the Lexica/JEI for the pinned module rather than invented here.

### Other module scope

`botania_extras` registers woods, flowers, Tree Suffusion multiblock, three environmental rods, additional blocks/capabilities and fuels. `exploration` contributes worldgen structure sets and loot; `magic_skies` is visual only when configured; `sophisticated` depends on absent mod and is not a reason to add forbidden Sophisticated Storage/Backpacks. Their content is **optional parallel quest breadth**, not a prerequisite to first base Gaia. Exact Botania Extras non-core devices and exploration loot remain to inventory.

**Evidence needed for deployment claims:** actual server instance `config/botania-common.toml`, loaded Terra Plate recipe registry, registered modid `avaritia` absence, unmodified output components, and real source Mana receipt/consumption. No JVM Minecraft, Prism, integration assembly, KubeJS or modpack configuration was run by the Atlas research.
