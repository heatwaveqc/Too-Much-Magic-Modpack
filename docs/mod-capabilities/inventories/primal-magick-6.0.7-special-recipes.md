**How to interpret:** `primalmagick:<id>` is mapped from the registered `ItemsPM` or `BlocksPM` source constant when a direct `.get()` appears. Other symbolic expressions, including Potion result constructors and tag constants, remain **literal Java expressions**, not invented item IDs. `default output ID` means generated builder's native default (Runecarving / Concocting) and should not be mistaken for a guaranteed final assembled JSON filename. Concocting built-in default Mana is **typed Infernal Mana** with amount derived from the `ConcoctionType` enum (`ConcoctingRecipeBuilder.defaultManaCost`); this pass preserves that symbolic input rather than guessing an amount. Dissolution builder `.defaultManaCost()` is a definite **10 Earth Mana**. The actual source builder's `.manaCost` multiplies displayed points by 100 to store centimana.

**Teaching implications:** The Runecarving Table consumes two distinct **ingredient slots** (first and second) and requires the specified native research; it does *not* use a Ritual salt network. Dissolution recipes transform an input plus typed Mana, and the nominal two-output stone variants are real source declarations but still require TMM worldgen/ore economy review. Concocting crafts **Tincture / Philter / Elixir / Alchemical Bomb** potion-item variants via actual ingredients and Infernal Mana, not free vanilla Brewing Stand conversions. Do not assert that 122 output callsites mean 122 freely available brewing effects.
