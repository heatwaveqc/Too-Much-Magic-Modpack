Recipes include several **distinct serializers**: `flask_effect` puts a named effect into a flask, `flask_effect_transform` transforms existing effects, `flask_item_transform` changes vessel form (splash/lingering), `flask_length` changes duration, `flask_potency` changes effect level, `flask_fill` replenishes doses, and `flask_cycle` changes ordering. Keep these mechanics separate from simply owning an Alchemy Flask; they may change components without changing base item identity.

`upgradeLevel` is the **minimum Tabula Orb tier**, `syphon` is source total Anima cost, `ticks` is nominal crafting duration. `inputEffects` and `outputEffects` refer to current/produced flask state, not items. `baseDuration`, `lengthDurationMod`, `powerModifier` and other fields must be interpreted by their actual serializer; not all are durations per dose. Flask effects can overlap with different potions but remain separate from simple inventory crafting.
