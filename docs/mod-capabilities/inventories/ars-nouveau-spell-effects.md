# Ars Nouveau 5.13.5 — native spell Effects: exact source default mana/tier and behavior

**Source:** [67 Java Effect classes in frozen Ars Nouveau 5.13.5](https://github.com/baileyholl/Ars-Nouveau/tree/4d323fba9200c3293a4f4848cf1e0fe70beb7098/src/main/java/com/hollingsworth/arsnouveau/common/spell/effect), independent of [82 generated glyph learning recipes](ars-nouveau-glyph-recipes.md). This file indexes every Java spell Effect with its per-part **default mana**, default tier, declared compatible augments, schools and native guide description. Spell part default cost is a **configuration default**, not a promised final per-cast charge; the full spell's cost combines a chain of parts and augments and may use custom constraints. [AbstractSpellPart.java](https://github.com/baileyholl/Ars-Nouveau/blob/4d323fba9200c3293a4f4848cf1e0fe70beb7098/src/main/java/com/hollingsworth/arsnouveau/api/spell/AbstractSpellPart.java) shows configured `getCastingCost()` and `getConfigTier()`. Vanilla Scribe's XP and TMM MXP are separate currencies.
