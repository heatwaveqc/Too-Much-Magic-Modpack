This file indexes every Java spell Effect with its per-part **default mana**, default tier, declared compatible augments, schools and native guide description. Spell part default cost is a **configuration default**, not a promised final per-cast charge; the full spell's cost combines a chain of parts and augments and may use custom constraints. [AbstractSpellPart.java](https://github.com/baileyholl/Ars-Nouveau/blob/4d323fba9200c3293a4f4848cf1e0fe70beb7098/src/main/java/com/hollingsworth/arsnouveau/api/spell/AbstractSpellPart.java) shows configured `getCastingCost()` and `getConfigTier()`.
