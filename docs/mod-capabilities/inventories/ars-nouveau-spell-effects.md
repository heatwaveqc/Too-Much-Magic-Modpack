This file indexes every Java spell Effect with its per-part **default mana**, default tier, declared compatible augments, schools and native guide description. Spell part default cost is a **configuration default**, not a promised final per-cast charge; the full spell's cost combines a chain of parts and augments and may use custom constraints. Vanilla Scribe's XP and TMM MXP are separate currencies.
