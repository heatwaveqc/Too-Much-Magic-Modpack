## Functional equipment (verified recipes and key methods)
- Living Bouquet creaturefeature:bouquet: Beauty player-kill loot pool chance .41 at zero Looting, .43 level1 +.02/extra level. BouquetItem durability16; useOn checks #minecraft:flowers block item, spawns one default flower stack without removing original, damages bouquet1. FlowerCloneRecipe matches two slots containing one flower and bouquet, makes two copy of flower, bouquet crafting remainder advances damage; exact terminal durability edge next. Potential tag interactions with magical flowers and economy require targeted audit. No pet interaction.
- Open Mind creaturefeature:open_mind: four iron ingots, blighted_brain (Minds loot), minecraft:crafter. use opens vanilla CraftingMenu using NoBlockContainerLevelAccess. Portable crafting grid, not persistent storage. inventoryTick/onDroppedByPlayer behavior and recipe gates next.
- Weathering Rod creaturefeature:weathering_rod: four copper ingots and remnant (Wraith loot); durability16; charge >14 ticks then release creates LightningDelayEntity at player position in server, movement based on look horizontal and charge scale 1+sqrt(t-14)/14, consumes durability. LightningDelayEntity creates vanilla LIGHTNING_BOLT; exact path/surface, strikes and permission next.
- Dreamcatcher actual recipe output creaturefeature:dream_catcher (locale has dreamcatcher); four dream_silk (Dream Weaver loot), two netherite_scrap. SpawnerCaptureItem uses DREAMCATCHER_CONTENTS component; on server with empty contents can capture eligible item-form block with nonnegative default hardness; saveToItem for block entity, explicitly rejects net.minecraft.world.Container BE, stores one item and destroyBlock(pos,false). Filled use places default block state at adjacent position if empty/replaceable, loads custom block entity data, clears contents. Not full block-state preservation; no obvious general claim check or placement/removal success check in visible path. Spawner relocation appears possible from broad BE path, not yet verified with spawner/loot protections. Risk audit required against existing TMM spawner policy, item data and claimed blocks before any quest tells players to use it on spawners. No gameplay patch.
- The Pill creaturefeature:the_pill: 2 carapace (Runaway) + sleeping_powder (Eeper) makes4. ThePillItem.finishUsingItem resets Stats.TIME_SINCE_REST for ServerPlayer. Does not remove existing phantoms; additional food/effect behavior next.
- Heavy Axe: heavy_core + 3 blitz_rod (Blitz Fragment); HeavyAxeItem.onLeftClickEntity/postHurtEnemy has addDeltaMovement, native horse advancement; exact weapon properties, affected entities and force next. 
- living_glass_shards (Stained Glass loot) LivingGlassItem.hurtEnemy selects effect from target active effects and removes it; tooltip says shatters. Exact cost, eligible effects and Vitric Arrow next; not a targeted self-cleanse.
- Doohickey: six gold ingots + thingamabob (Machination loot); BlockEntity keeps placed item saved doohickey_item, visual particle selection based on placed sleeping_powder, minedflayer_goop, vertigo_horn, bacterium_ball, fiendish_essence.
