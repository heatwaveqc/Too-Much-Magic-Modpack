## Current-release checks

- Enumerated immutable source tree (not truncated): 22 Tile* device classes, including altar/attunement, tree beacon, gateway, lenses/prisms, focus crystal, Lightwell, Chalice, infuser and lumen machines. No standalone legacy ritual pedestal, collector crystal, grindstone or Mineralis ore-generation implementation/recipe identified in the inspected paths. Mineralis is a recorded minor constellation, not proof of that old ritual mechanic. Do not credit old Ritual Pedestal effects, legacy Mantle of Stars or generic ore generation without current survival evidence. This is a source-tree negative finding, not exhaustive binary impossibility proof.
- [Formation Wand](https://github.com/HellFirePvP/AstralSorcery/blob/e5309e9cc82dfe96d0fc7b04aaa5c56692d47f55/src/main/java/hellfirepvp/astralsorcery/common/item/wand/ArchitectWandItem.java) uses actual inventory blocks for noncreative placement, checks placement event, base plane/solid sphere radius 2, lumen-boosted radius 5, hollow sphere outer/inner 3/2 or boosted 5/4. Lumen cost constant 0.3/block. [Conversion Wand](https://github.com/HellFirePvP/AstralSorcery/blob/e5309e9cc82dfe96d0fc7b04aaa5c56692d47f55/src/main/java/hellfirepvp/astralsorcery/common/item/wand/ExchangeWandItem.java) uses inventory replacements, checks block placement event, hardness limit 50, selectable radius 2–5, base block caps 16/32/64/128 and boosted 64/128/256/512, cost constant 0.15 lumen/block. These are native defaults and selection caps, not guaranteed actual placements or a proof of claim compatibility.
- [Gateway server request](https://github.com/HellFirePvP/AstralSorcery/blob/e5309e9cc82dfe96d0fc7b04aaa5c56692d47f55/src/main/java/hellfirepvp/astralsorcery/common/network/play/PktRequestGatewayTeleport.java) validates player at gateway, source structure and sky, target dimension and registered destination, target structure and sky, then transfers to target dimension/position. No payment in this handler. No claim of arbitrary-coordinate teleport or TMM-specific access restrictions.
- [Phoenix Blessing](https://github.com/HellFirePvP/AstralSorcery/blob/e5309e9cc82dfe96d0fc7b04aaa5c56692d47f55/src/main/java/hellfirepvp/astralsorcery/common/perk/tree/perk/key/KeyPerkCheatDeath.java) listens to LivingDeathEvent, checks server player, active perk effect and cooldown; sets health to 1 HP, applies Regeneration III for 400 ticks (20 seconds), plays totem sound and cancels death. Default cooldown 1800 ticks (90 seconds), configurable, explicitly does not scale with perk effect. Unlike Primal/Extra Botany it does not clear all effects or add absorption in this handler. Distinguish separate Aion Stardew effect; no assumption of identical cooldown or stacking.
- [Bigger Stomach](https://github.com/HellFirePvP/AstralSorcery/blob/e5309e9cc82dfe96d0fc7b04aaa5c56692d47f55/src/main/java/hellfirepvp/astralsorcery/common/perk/tree/perk/key/KeyPerkReducedFood.java) reduces exhaustion up to 0.005 per server tick when positive; not free food creation. [Vivid Growth](https://github.com/HellFirePvP/AstralSorcery/blob/e5309e9cc82dfe96d0fc7b04aaa5c56692d47f55/src/main/java/hellfirepvp/astralsorcery/common/perk/tree/perk/key/KeyPerkGrowPlants.java) samples nearby valid plants and attempts growth; default chance parameter 1.0, radius 3, scales with perk effect and may attempt multiple growth ticks. Not guaranteed growth for every plant.
- [Tree Beacon](https://github.com/HellFirePvP/AstralSorcery/blob/e5309e9cc82dfe96d0fc7b04aaa5c56692d47f55/src/main/java/hellfirepvp/astralsorcery/common/tile/TileTreeBeacon.java) captures grown tree snapshots and produces actual block drops, default range 12, harvest chance denominator 15 and wear chance denominator 800 per relevant trial, not a fixed item/tick rate. Starlight affects cycle count, shadow maintenance needed. [Chalice](https://github.com/HellFirePvP/AstralSorcery/blob/e5309e9cc82dfe96d0fc7b04aaa5c56692d47f55/src/main/java/hellfirepvp/astralsorcery/common/tile/TileChalice.java) capacity 64 buckets, automatically draws matching liquid starlight from eligible Lightwell underside handler, simulates fill/drain before actual transfer; specialized fluid storage only.
