TMM pinned `irons_spellbooks-1.21.1-3.16.3.jar`, [29-axis source-backed dossier](irons-spells-n-spellbooks.md), nine per-school exact 111-spell source inventories. **15 main foundations + 49 optional branches.** A quest author is free to consolidate optional lessons. Main lane teaches one real working Scroll-Spellbook cycle and does **not** require all nine schools, all 111 spells, special loot, or boss kills.

**Detection honesty:** Native `SpellData` is a Minecraft item data component. Basic FTB item possession cannot prove spell ID/level, successful Scroll Forge crafting, completed `InscribeSpellEvent`, actual Mana cost, Curios equipment activation, spell effect, protected-block refusal or boss *first kill*. The rows below specify necessary **observable proof**. Until TMM implements server-originating advancement/FTB task criteria, call these manual/source research checks, not automatic detectors. Never equate loot item with a kill or cast attempt with completed paid cast. Casting without exact spell must remain optional if the spell `allowCrafting()` is false or loot-only.

**Balance boundary:** Native `max_mana` base100 and per-spell mana source defaults are **not the loaded TMM mana config**; server spell JSON may override it, and Ars 'n Spells may participate in paid-cost settlement. **MXP is global progression**, not owned by Iron's Path or by this quest chapter. Source 3.16.3 ServerConfigs `spellGriefing=false` is a default only. Avoid rewards of legendary ink, boss keys, unique spells, phylactery, Rare potion reagents, TMM gated drops or guaranteed first-boss credit.
