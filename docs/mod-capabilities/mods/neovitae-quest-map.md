# Neo Vitae — primary quest-source map (Atlas pilot, v0.1)

**Status:** **research proposal**, not a quest implementation, detector test, gameplay PASS, reward approval, or final complete chapter. Part of [Neo Vitae capability dossier](neovitae.md), [registry index](../inventories/neovitae-registries.md) and [29-axis field guide](../AXIS-FIELD-GUIDE.md). Source aligned with the current TMM pin **1.21.1-1.1.53** but exact compiled JAR match and in-world behavior are unverified. All quest IDs below are **research IDs**, not FTB's real GUIDs; they cannot be pasted into an SNBT chapter without separate authoring and stable-ID reconciliation.

## Existing pack quest crosswalk

Current `test/full-integration/config/ftbquests/quests/chapters/neo_vitae.snbt` contains **one optional checkmark** (FTB quest GUID `544D303000E00001`) with 2 XP and 1 Paper reward; no recorded teaching of guide access, altar operation or tiers. This is a **placeholder**, not a chapter. Preserve original GUID/reward intent until the quest owner reviews replacement; do not silently duplicate those rewards or remove the old chapter.

**Target standard:** a player using **questbook + JEI + Scriptura Vitae only** should reach the first real setup, build successive recognized Ara Vitae tiers, access key side systems, and complete a meaningful terminal use. The questbook should teach real operations and point to specific Modonomicon or JEI pages; recipe possession, boss item ownership and fake-operation claims do not satisfy that standard.

## Proposed dependency structure

```text
NV-01 Guide
  → NV-02 Ara Vitae tier 0 → NV-03 Novicius Orb → NV-04 item EV vs Anima
  → NV-05 Tabula Rasa / Tabula Vitae → NV-09 tier I / Discipulus Orb
  → NV-06 Alchemy Array → NV-07 Raw Spiritus → NV-08 Hellfire Forge
  → NV-12 tier II → NV-13 first ritual → NV-15 Demon Antechamber
  → NV-16 Tau/Weak Shard/Bloodstone → NV-17 tier III → NV-18 Endless Realm
  → NV-24 tier IV → NV-27 tier V → NV-28 Divinus Orb → NV-36 capstone
```

**Side branches** may open when their prerequisites are met; they must not be forced into an arbitrary single line. Proposed rows below include meaningful optional Sigils, potions, ore processing, cultivation, routing, equipment, machine automation, dungeon exploration, pet handling, Soul farming, and compatibility. **Do not assert** a mechanic is unavailable before it appears in the suggested quest spine: this is an instructional order, not an independently imposed game-level gate. Some mid-tier prerequisites still require exact recipe reconciliation.

## FTB detector truthfulness and authoring rules

**Unverified task types:** The current Neo Vitae placeholder proves only that a manual checkmark task is configured. Source research of Neo Vitae does not demonstrate any FTB-provided event for "altar recognized tier N", "Anima increased", "rite successfully activated", "Spiritus Aura deposit", "Sanguine Crafter completed operation", "Foreman boss killed", or "entered this dungeon instance". Treat each as `unknown` until the actual installed FTB Quest task types, advancement triggers, event hooks and source registry are inspected. A later first-party true-operation detector would be a **separate approved implementation**. Item possession may be used as a **clearly labeled proxy** only where author instructions still teach the actual use.

**Corrected source-derived progression order:** Tabula's physical block and some `upgradeLevel:0` recipes work with Novicius (NV-05); **do not place NV-06 Scribe or NV-07 Throwing Daggers before Tier I Discipulus (NV-09)**. Binding Reagent for ordinary Sentient Armor is a `upgradeLevel:3` Tabula recipe, so **NV-14 requires Tier III Magus/other tier-3 Orb** (NV-17). Normal Sentient Evolution is a `crystal_level:1` ritual; the only sourced Awakened Crystal recipe is at Ara Tier IV, so **NV-23's evolution portion is after NV-24**, even if armor training is earlier. The two dungeon-portal rituals use Weak Crystal **80,000 EV** (Antechamber) and **150,000 EV** (Endless Realm), source constructors, and can remain mainline at II/III. No bypass route was verified.

**Mandatory gate versus optional learning:** Ara Vitae tiers are real, not quest-invented; the player can progress when Minecraft-side requirements permit. Assign one or more optional teaching quests to every major subsystem but do not force every array recipe, armor upgrade, anointment or flask effect into a mandatory chain. For alternate ritual/faction/portal routes, preserve actual game alternatives. A capped species/item blacklist is a game rule, not a quest reward.

**Proposed reward policy:** All directions above suggest **positive XP + an inexpensive fixed thematic item** and deliberately omit exact payout numbers pending the quest/economy owner. At higher tiers, "safe decorative material" is preferable to boss keys, Rune/Orb tier-gate components, high EMC-value materials, weak blood shards, mine keys or advanced Aspect catalysts. A source proposal does **not** authorize rewards or actual SNBT modification.
