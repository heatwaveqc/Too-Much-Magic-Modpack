## Entry, casting and resource economy
Find natural amethyst geodes; non-Silk cluster harvest with qualifying tool provides dust1–4 + Fortune scaling, charged crystal chance25/35/50/75/100% Fortune0–4 in packaged loot. Lesser tools lower drops; leave budding blocks to regrow. Root inventory_changed tag accepts dust/shard/charged (not just charged). Craft book+amethyst dust -> Patchouli guide_book component hexcasting:thehexbook; open Hex Notebook; explicit early guide onboarding; no automatic grant claim. Staff recipe oak example charged crystal+3 sticks+one matching plank. Staff use opens grid; click-drag patterns, actions execute on completion, sneak-use clears. Basic read-only demonstration Mind's Reflection (get_caster) then Compass Purification (entity_pos/eye), observe position vector; use guide casting/101 for actual drawing. Ordinary action rotation irrelevant, Great Spell signatures world-specific. Iotas nine registered types null/double/boolean/entity/list/pattern/garbage/vec3/continuation, stack-based operations; serialization depth256,total1024 distinct from stack/operation limits. Read the Notebook patterns/readers_guide, casting/stack, vectors, influences, mishaps; no full language lesson plan.

Default Media dust10k, shard50k, charged100k, whole item may be consumed/wasted for smaller cost, shard->4 dust sacrifices 10k value; spend per action. MediaHelper player inventory+armor+offhand, priorities then available descending; Curios not directly scanned. No standardized FE/mana/blood/Source/Psi bridge. Staff creative exemption; safe initial insufficient Media fails; after failed Great Spell advancement allows health overcast at default10k/HP, minimum .5HP damage request. Actual damage converted to Media, trigger/stat records. Native game damage may kill; no fixed numerical recipe blindly applied to modded max health. Phial and packaged batteries continuous charge reduce waste. Phial creation Great Spell with single glass bottle held and dropped Media entity, one crystal overhead plus actual charge; recharge costs one shard, held rechargeable with available capacity, transfer dropped Media. Guide phials/hexcasting and pattern recharge. Native config can modify denominations, cooldowns, harvest tier, action denylist, circle denylist, teleport dimensions; source defaults not pack effective.

## Significant world actions, range and flight
Player ambit32 from caster position, Greater Sentinel (2 dust, gated) extends radius16 around one persistent position same dimension; ordinary Sentinel1 dust marker, create target must be in range, query/wayfind/destroy. Actual assertEntityInRange checks world and vector reach even for Player, unlike isEntityInRange helper's exception and book's general unlimited true-name promise. Specific action using assert is range-restricted. Player edit permission excludes adventure and uses world.mayInteract, platform placement checks where present; pack claim integration separate.
Break Block 1/8 dust, one target, edit range, nonair/nonnegative hardness and correct configured harvest tier (default diamond3), destroys with drops and caster. Place Block 1/8 dust plus real held eligible BlockItem and replaceable target, uses placement check/withdrawal. Conjure light/solid block one dust, replaceable + edit checks, pigment color; no assumption harvest for unlimited EMC. Create/destroy water, ignite/extinguish, bone meal, edify saplings, cycle variant; lava creation one crystal gated, vanilla cauldron/bucket style, no invented universal fluid conversion. Direct damage through explosions/lightning, motion, poison/wither; no direct instant heal established. Beneficial regeneration/night vision/absorption/haste/strength gated; ordinary weakness/levitation/wither/poison/slowness. OpPotionEffect duration seconds, amplifier int(potency)-1, cost base*duration*potency^2 ordinary or ^3 beneficial, potency positive<=127 where applicable, fixed1 for levitation/night vision; finite effects. 
Blink within range origin and destination, signed look-distance, cost half shard/block; permitted dimension and entity portal/tag checks. Greater Teleport fixed ten crystals, target in ambit, vector displacement destination world-valid (not ordinary ambit), same-level only, default dimension deny Twilight Forest; sticky passenger handling, not guaranteed safe landing. Self-GTP may drop entire inventory stacks probability distance/10000 (hotbar half, armor quarter, excludes main/offhand, Binding armor); no risk-free waypoint teleport. Native flight/range costs dust per radius block; flight/time shard per second, grants mayfly until limit/dimension expires, doesn't clobber pre-existing mayfly. Altiora Great Spell one crystal, upward launch and airborne glide/collision-end after20t grace. All are compatible with owner's accepted temporary paid flight; no permanent no-cost creative flight gate change.

## Spell circles
Craft empty Impetus (2 purpur+4 slate blocks+2 iron bars+charged) and use Flay Mind appropriate recipe. Empty Impetus routes but does not initiate. Arrange slates/connectors closed path with unambiguous exits; geometry can bend in 3D; write patterns into slates, place with direction as Notebook, feed Impetus Media via hopper/item, check lens, trigger. Toolsmith rightclick, Fletcher look30 ticks (20-block search AABB, ray length20/1.5, carved pumpkin exclusion), Cleric rising redstone; use own player-reference holder on Cleric to bind, sneak empty-hand clears, same-level online player resolution or null. No-caster circle cannot meet Great Spell gate. Mason Directrix redstone chooses output; Empty Directrix 2 comparator+4 slate blocks+2 observer+charged, book indicates random routing for empty; don't teach random as deterministic. 
**Binary vs guide:** CircleExecutionState flood-fills possible exits, requires return path, cuboid of discovered components incl potential branches; BlockSlate executes immediately with CastingVM and updated image, empty slate passes state, zero or multiple valid exits/mishap halts, previous effects are not rolled back. Schedule max(2,10-(visited-1)/3) ticks, usedOps reset per slate; config maxOpCount default1m actual PatternIota check. Config advertises maxSpellCircleLength1024 but no execution consumer found by whole archive class constant scan, no guaranteed length limit. Impetus huge finite capacity9e18 internal units, creative unlocker infinite not ordinary survival. Circle draws own stored Media not player health/inventory. CircleCastEnv default block edit permission true, item stack query empty and replaceItem false; some actions cannot operate because no held items, world-placement hooks may apply. Circle vector bounds plus Greater Sentinel same dimension radius16, NOT guide's bound-Cleric-player remote area. Do not assume claim or server performance safety. For first lesson simple harmless effect inside loop, observe each action; later redstone routing/automatic crop or world operation using supported action (not all staff actions work in circle). Separate pack review for claim protection, budgets, repeatable automation, null caster, actual effective configs.
