## Recommended first-time progression topology

**Core steps are a minimum teaching spine, not enforced by pack gating**: Refined Soulstone + Guide → Crude Scythe → soul exposure/reaping → Spirit Altar + first Hex Ash infusion → Soul-Stained Steel & first three-pole Totem → first major four-pole Rite → Spirit Crucible. Later Soulwood, Runes, Geases, Artifice, Repair Pylon, Weeping Well/Umbral and optional Gaze are lateral/advanced paths. Don't require every rite or 938 native recipe files to finish the chapter, and do not put creative-class rewards into progression.

## Detector honesty and implementation boundary

- **Guide/gear/crafting:** FTB Item tasks can prove specific outputs such as Refined Soulstone or Crude Scythe; teach the actual use in description, since inventory possession doesn't prove correct operation. Avoid pay-to-skip item rewards for high tiers.
- **Soul Exposure:** A named `malum:spirit` inventory item does NOT prove that a particular player correctly exposed an eligible mob before its death. Unless the active FTB mod has a known advancement/event task wired to Malum's soul reap handler, use a clearly labeled instructional checkmark or request an authorized per-player adapter; don't silently claim automatic true-operation verification.
- **Rites:** Totem Base Item presence does not prove exact ordered carved pole geometry, activity state or target effect; a truthful detector would need block entity state/actor attribution or a native advancement. The number of Spirit types and Rite IDs cannot be used as direct FTB system object IDs without proper custom adapter.
- **Geases:** The `soul_binding` JSON result is a **GeasEffectType applied to the targeted LivingEntity during a 600-tick Soul Brazier ritual**. It does **NOT** produce a Geas Item. Input Ether begins BIND, Paracausal Flame begins UNBIND; intended target takes 25% maximum health as Karmic sacrifice, failure another 50%. Quest reward must not encourage lethal unprepared tests or fake acquisition of a nonexistent craft result. Check `GeasSoulData` attachment when an adapter exists; otherwise use owner-honest manual instruction.
- **Imp­etus:** Crucible must spend recipe Spirits, time and durability; a Node item task alone will not prove the exact tool and timer. Uranium recipe is NeoForge conditionally loaded based on nonempty `c:nuggets/uranium`; don't require it if absent.
- **Pouches:** `ML-15`/`ML-16` explicitly OWNER HOLD under the pack's no-generic-backpacks rule. Source pouches are bundle-like general item inventory, not magic-only. No approval of survival recipes, rewards or replacement has been inferred from studying them.
- **World:** Undirected/Unchained can alter terrain; keep tutorial on safe disposable plots. Weeping Well player rejection deals up to 4 HP in ordinary survival and special reward access has a streak condition; do not call it harmless.
- **Gaze:** Publisher advertises progress UI, +2 Geases, more Rites, six weapons, eight runes, five Curios and a pouch, but **source exact item/recipe IDs unknown** in this audit. Treat ML-42/43 as placeholders, **not** implemented or mandatory FTB tasks, until Gaze 1.1.7.1 JAR/source and actual pack config reviewed.
