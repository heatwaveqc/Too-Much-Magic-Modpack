- **Main spine** uses Native First Age Dark Gem and **either loot-book or optional portal guide route**, Second Age Blood Extractor, **world five-source first Power Gem → real Infuser 250mB repeat**, tier0 Bowl+Iron Acceptor and first **machine** Promise. This is deliberate teaching order, not an assertion that the in-game book is required for every native advancement. First Age spirit/temple optional branches remain available independently.
