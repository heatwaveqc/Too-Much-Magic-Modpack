**Task detection rule:** A generic FTB item task proves **possession** only, not that a player infused it, actually gained mB Blood, opened the book, mounted a Broom, operated a Furnace, collected spirit loot, or ate a Blood-powered meal. Native `first_age` is Dark Gem inventory, `second_age` is Extractor craft, `evil_source` is guide possession; custom capture/distort/necromancy triggers may allow stronger tasks only if a working FTB/advancement bridge exists. Prefer clear manual instructional proof or implementing exact per-player event predicates separately. **No boss first kill from a synthesized skull/star/loot item**. All reward directions are low-value XP/ordinary items, not literal implemented grants.

## Authoring notes, evidence ownership and next source pass

- **Main spine** `EC-00…13` uses Native First Age dark ore/portal, Second Age Blood Extractor, **world five-source first Power Gem → real Infuser 250mB repeat**, tier0 Bowl+Iron Acceptor and first **machine** Promise. This is deliberate teaching order, not an assertion that the in-game book is required for every native advancement. First Age spirit/temple optional branches remain available independently.
- **Tier chain** EC-14/15 optional uses **Tier1 40k Gold Acceptor** and **Tier2 160k Diamond Acceptor** before eventual Tier3 640k tank, without the tier3 bowl self-gating mistake. EC-16/17 Speed/Efficiency are separate alternative upgrades, and EC-18…20/42 demonstrate actual named Infuser synthesis instead of arbitrary transmutation.
- **Resource scopes** EC-05 credited-kill extraction vs EC-06 fall-stain vs EC-31 Sanguinary Pedestal/plate are separate; free world Blood generation not assumed. Default machine transferrates and redstone behavior are source only. EC-25–27 Broom uses **1mB/tick** fuel, not free Creative flight.
- **Native hazard education** EC-33–43 explicitly teaches spirit sight/capture/protection, valid Furnace multiblock and **Reanimator's default box-clearing on unsupported egg types**; mob/boss farm gates remain existing TMM capture/spawner policies, not new owner decisions.
- **Garmonbozia and diet** EC-39 player-kill Vengeance Essence→8 Crushed Gems materialization→tier3 50k Blood Garmonbozia→Flesh+Garmonbozia→Custom Rejuvenated Flesh cost 250mB/bite. Cross-species `Magical` food eligibility must preserve custom drain and is not proven for all existing Dragon/JAWR transformations by the source alone.
- **Environmental safety** EC-21–24/45 weather and biome operations are optional, use source-conditioned recipes, and must respect changed dimensions/claims if TMM later implements related protections. No automatic proof a real biome changed from only a filled bottle.
- **Existing chapter** `config/ftbquests/quests/chapters/evilcraft.snbt` still contains the optional checkmark/2XP+Paper placeholder according to pinned Mod Comprehension; **this Atlas modifies no integrated quest file**. Native book and JEI references may have 1.2.98 public HTML mismatch: always use installed Origins of Darkness.
- **Static QA:** 46 unique lesson IDs; **14 Core +32 Optional**; all dependencies point to existing IDs and form an acyclic DAG. No actual FTB task predicates or in-game rewards were authored. **First-pass open factual research:** not every one of 127 basic crafting variants or dungeon/temple loot tables analyzed, Broom/utility item cost specifics still partial, and effective TMM canonical Blood and per-species use/loaded config need narrow integration testing rather than a repeat survey.
