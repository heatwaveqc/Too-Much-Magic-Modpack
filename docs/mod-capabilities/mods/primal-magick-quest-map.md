# Primal Magick 6.0.7 — first-pass quest-source dependency map

**Scope:** **40 unique proposed instructional labels** (12 Core, 27 optional source/gear branches, 1 optional finale), with all prerequisite edges pointing backward. These are **Atlas research IDs, NOT 40 live FTB Quest GUIDs**, no actual tasks/rewards/chapters/scripts are committed, and no in-world tests were performed. Keep the existing TMM first-party chapter state and any owner-authored GUIDs intact when implemented later. Sources are official [tag 6.0.7 immutable snapshot](https://github.com/daedalus4096/PrimalMagick/tree/5977468bda968b994e54066236ec5719295ac9c3) and [previous detailed profile](../../mod-comprehension/mods/primal-magick.md), not an independently unpacked published JAR.

**Design rule:** do **not** convert all Primal Magick native research entries into mandatory FTB quests. The source has [298 research keys /38 randomized Theorycrafting templates](../inventories/primal-magick-6.0.7-research-and-spells.md), so the goal is instruction, not forced completionism. Display native Grimoire and JEI instructions where applicable, give real player operations and explicit objective types, and distinguish recipe/stage completion from mere item possession.

## First common spine and specialist branch graph

**First player loop:** Shrine → dream upon waking → starter Mundane Wand → bookshelf → Grimoire → Arcane Workbench → 10 native Mana siphoned → first Observation → analysis → Theory Table / first successful Theory → unlocked Manaweaving/Mana Prism.

**Native research dependencies (verified in `ResearchEntries.java`):** Mana Arrows → **Alchemy**; Wand Charger → **Sorcery**; Basic Calcinator → **Runeworking**; Wand Inscription **and** Rune Project → **Ritual**; Manafruit **and** Mana Salts → **Magitech**. The first stages of these unlocks require one Observation. They are research parent edges, not invented pack gating.

**Native long game:** Basic → Expert → Master → Supreme per-discipline Expertise; Source discovery / attunement Earth/Sea/Sky/Sun/Moon → Blood/Infernal/Void → Hallowed; six specialist finales + Basics; hidden Theory of Everything requires all seven discipline finales and all nine Source attunements at level two. Spells, Runes, Mana network, Alchemy and Ritual material loops remain meaningful throughout. `MundaneWandItem` has **zero spell capacity**, so no beginner spell-cast task is allowed.

## Explicit quest authoring distinctions and safety

- **Early triggers:** `found_shrine` / `got_dream`, `first_steps` staged craft, `mana_siphoned` and `observations_made` are native player-local research/stat state. Any FTB adapter must choose real per-player or explicitly owner-approved team credit. A Dream Journal in inventory is only a possession proxy. Never tell a player to sleep before seeing a shrine expecting guaranteed dream progression.
- **Source typed costs:** Earth, Sea, Sky, Sun, Moon, Blood, Infernal, Void, Hallowed are distinct resources. A generic FE battery or Ars Source jar does not satisfy Primal Magick Source costs by default. A research tier and a Mana Source are different things.
- **Spells:** spell package is **vehicle + payload + zero to two mods** with player-dependent unlocks; don't require all 24 payload types or force casting with Mundane Wand. Block break / lava / flight / teleport / conjure effects warrant claim-and-permission checks when TMM adds quests.
- **Theorycrafting:** there are 38 registered randomized templates. Choose representative accessible projects rather than demand one of each; require actual Theory award/field change, not just Research Table ownership. Material consumption/XP/Observation corner cases merit focused QA for observed pack symptoms, not blanket upstream regression.
- **Ritual safety:** real ritual altar needs connected salt, pedestals, props, typed Mana and recipe requirements. Negative stability can drop/destroy offerings, damage players or detonate; Dowsing Rod diagnostics should precede a safe, exact recipe. **PM-29 is intentionally not a proof-backed recipe until the 6.0.7 ritual JSON has been enumerated**. Never script player damage/death as required to pass a quest.
- **Endgame:** hidden `theory_of_everything` and `secrets_of_the_universe` are real native research goals; neither is a TMM creative-class reward shortcut. `mana_singularity_creative` must follow common TMM creative policy #596, not independent Primal quest rewards.
- **FTB implementation boundary:** source-proposed item + XP rewards can be modest and thematic, but none are approved here. Preserve actual chapter/task GUIDs, choose correct one-time actor criteria, prevent nested portable storage on any optional items, and run static checks before scoped gameplay verification when separately authorized.
