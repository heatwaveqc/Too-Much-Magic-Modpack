## Main teaching thread — revision, not new tier gates

The native critical path is Notebook access (guide) → Novice Book → first valid spell → Scribes Table selected glyph/XP/consume-to-learn → Source link + Jar → Imbuement/Apparatus → Apprentice Book → Summon Wilden + three parts → actual Chimera kill + Tribute → Archmage Book. **Only the spellbook tiers and material inputs are native hard gates.** Source, 23 other rituals, armor, helpers and addon directions are branches unless explicitly needed to craft those inputs. Rewards must not give away rare Tier-3 gating materials or change underlying recipe EMC.

**Hard correction:** Source and player mana are different. Source Gems are material items. Vanilla XP spent on Scribes Table is not TMM MXP and not player mana. Ars 'n Spells cross-mana is **reported by the owner to be working**; it does not require a new balance decision to document its native cast/binding pathway. Its exact effective configured mode is not independently established by this source-only Atlas, so avoid asserting a particular enum. Use [third-pass compound spell economics and validation](../inventories/ars-nouveau-compound-spell-economics.md) for concrete formulas and 15/20/35/50/60-mana defaults.
