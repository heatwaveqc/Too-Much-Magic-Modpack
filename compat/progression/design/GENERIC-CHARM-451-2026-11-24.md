# Generic Charm — CT-01, #451 (2026-11-24)

First executable slice of the approved Charm/Taming workstream. Existing engine only; no new active keybind, packet, native JAWR patch, mob type conversion, or permanent allegiance. Target-specific 600 ticks, ordinary server entity reach, damage breaks; configurable cooldown default 40 ticks, no default cost. Reference exact pinned JAWR Transfix audit in #451. Minecraft 1.21.1 mappings confirm Player.canInteractWithEntity(Entity,double), Raider.hasActiveRaid/isCaptain, Pillager crossbow mob and Vindicator goal-based AI, RangedCrossbowAttackGoal target validity/stop methods; NeoForge LivingDamageEvent.Post is after actual health modification. API/source evidence only; actual AI timing and cross-mod interactions not yet observed.

Declarative effect on an existing Path skill (example only, no actual Path unlock shipped):
```json
{"type":"charm","target":"#example:eligible_mobs","params":{"cooldown_ticks":40,"requires_sneaking":false}}
```
Optionally add `"resource":"example:mana","resource_cost":10`. Strict explicit exact ID/tag (not wildcard), positive integer cost and known catalog resource; cost and cooldown independent of skill rank. Existing skill ownership, conditions, and activation/empty-hand/armor checks apply. Main-hand empty right-click, optional sneak gate, same-level, native reach without additional distance, LOS, connected survival/adventure, not Newbie. Respect canceled interaction, one effect sorted by canonical ID and one successful resource debit. Refuse already-active recasts (including other casters) without spending; cooldown shared across Charm effects for that player, persisted in existing modes; no hard cap on separately charmed mobs, no area casting. No new Path data or defaults beyond approved behavior.

Persisted mob attachment contains absolute overworld game-tick expiry (continues while chunk unloaded and server running, not while stopped); expired/invalid state removed on tick. Clear current hostile target and navigation, refuse new targets at LOWEST, clear preexisting target before tick, cancel outgoing damage attributed to charmed mob as last safety backstop (including already-fired projectile impacts while charm remains active). Nonhostile movement/AI stays native; no NoAI or goal removal. Positive post-mitigation damage to charmed mob immediately removes state, environmental damage included; zero/canceled hits don't. Normal hostile AI resumes; no immunity or ownership conferred. Applying after resource preflight and single-threaded local attachment update is not a crash-atomic multi-entity disk transaction. Existing interaction cancellation respected; actual modded claim protection precedence pending QA.

Deliberately limited supported IDs for first slice: ordinary vanilla Pillager, Vindicator, Zombie, Skeleton (no mounted/ridden mobs, custom-named special mobs, boss-exempt tags, active raid or raid captain). Even these require explicit Path target selectors and live AI QA. No other modded mobs or spellcasting Evokers until separately reviewed target adapters. The allowlist is an engine compatibility boundary, not the final Sexy Demon eligibility policy. Non-default config that matches unsupported targets refuses without cost. Taming CT-02 remains separate: persistent owner UUID, native goal adapters with follow/defend/sit/target allegiance and exclusions, no artificial companion count; no implementation/ownership conferred here.
