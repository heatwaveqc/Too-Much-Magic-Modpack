## Recommended narrow implementation

One shared quote transformation helper and three audited native quote-construction callsites:
1. ArsCastPayments.quoteEvent wraps only invocation of QuoteService.quote(Player,ResourceUnit,double,CostRules,CarrierPolicy), before Plan construction. Subsequent queries use cached immutable quote. No mutation/deduction on quote-only path. Keep raw origin/cross breakdown; Ars cross event display originally uses origin times premium (not native payment leg); do not multiply a freshly posted cost repeatedly, treat display parity as separate verified presentation work.
2. IronsCastPayments.quote wraps StandardQuotePolicy.quote(ResourceAmount,CostRules,CarrierPolicy,double,double) for initial plan; player explicit enclosing arg. The private plan quote is also used by canAfford/ensurePlan. Use authoritative spell school selector, not payer unit.
3. IronsCastPayments.price wraps its second StandardQuotePolicy.quote call only when final posted event cost differs from spell.getManaCost(level). If not changed, reuse already-discounted plan.quote; never discount same quote again. Keep captured rate from plan where feasible for long invocation/channel reprice; rank/allocation change during windup must not desynchronize quote and reservation. stateNativeCost then exposes the converted discounted amount to native checks; full-scroll settlement and per-pulse channel forecasts use the same transformed quote. No changes to native write/hold/commit/refund/cleanup or cooldown.

Proposed arithmetic (clarify in code review): discount **final positive mana legs after native conversion/rounding**, using existing ceil/min1 and max95% Thrift semantics per leg. Already-zero legs remain zero; do not create free positive leg, change payer, or discount LP/aura/non-mana. Preserve origin, pricing generation and existing breakdown; append stable tmm_thrift factor/step (including note rounding per positive paying leg) and reconstruct immutable native CostQuote via a verified small adapter, no upstream code import. Marker prevents double application. Using final paying-unit rounding is an implementation choice, not a newly approved balance standard; it preserves positive legs and baseline one-to-one behavior; compare origin-first rounding if owner prefers. At 1:1, native 20 with 25% is 15, MXP uses original nominal20 (200 base at pool100). 25 native converted mana example native 20 cross1.25 ->25, Thrift25% ->ceil18.75=19. At split small costs, per-leg min1 may mean no saving. If source is entirely free remain free and no MXP. Original nominal remains existing E2 receipt, not sum of final legs and not discounted origin. No price setting or rank change proposed.

Separate guard/rate method: retain MxpMod.active, legacy Tyz, newbie, real server player and positive finite original rules; evaluate only matching originating Ars or Iron magic_cost_discount skill, never add both just because shared pool. ANS-specific quote helper bypasses blanket current native hook guard only for those explicit paths; continue suppressing old native spend/getter discounts when ANS manages the cast. Nonmanaged disabled-mode Ars fallback still needs matched pre-affordability and native payment cost proof before enabling. Native Iron exempt/proxy/free scroll/recast/creative remains exempt; paid cross proxy delegates to real Ars receipt, not outer Iron. Full-scroll opt-in must charge once only. No skill-tree activation. Optional types: use supported exact compile/runtime linkage strategy or narrowly verified reflective bridge; if ABI unavailable leave original quote unmodified rather than half-apply. No broad interception at BridgeManager.consumeQuote or StandardQuotePolicy globally.
