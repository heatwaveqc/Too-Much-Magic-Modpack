For weights 100/50 and min cracked, seed = 2/4 dust units; a weight-50 min-flawless gem = 64 dust units. Fixed relative seed, then each real effective cutting alternative consumes 2 identical gems, dust and one valid right-slot reagent; least-cost ProjectE graph selects valid path. No global price for the invalid bare gem item. Reference weight and multiplier are proposed tuning inputs, not approved absolute prices. Constraints (dimension/world tier) are not independently surcharged yet. Avoid copying stored gems with arbitrary extra payload. Impetus untouched.
